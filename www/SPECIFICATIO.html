Spécification officielle de MonLangage

Cette page décrit les fonctionnalités réellement présentes dans l’interpréteur de cette version de MonLangage.
aide(spec)
1. Statut et architecture

MonLangage (MLG) est le langage interprété par le moteur présent dans www/index.html de cette application.

Cette spécification décrit l’état fonctionnel de l’interpréteur fourni avec le projet. Elle ne promet pas de fonctionnalités qui ne sont pas présentes dans l’implémentation.

.mlg est l’extension des fichiers de code source MonLangage. .mld est l’extension utilisée pour les sauvegardes de données produites par les fonctions de fichiers.

Le projet Android est construit avec Capacitor. Le dossier www/ est la source web embarquée dans l’APK ; SPECIFICATION.html est donc livré hors ligne avec l’application.

aide() est la documentation interactive. aide(nomOuSymbole) donne l’aide d’un élément. aide(spec) ouvre le présent manuel officiel dans un écran dédié.

2. Syntaxe générale

Les instructions structurées utilisent des parenthèses (...) pour leurs paramètres et des accolades { ... } pour leurs blocs.

Les textes littéraux sont écrits entre barres verticales |...|.

Les commentaires commencent par ** et vont jusqu’à la fin de la ligne, sauf à l’intérieur d’un texte littéral |...|.

Les indices commencent à 1, et non à 0.

Les paramètres nommés utilisent la forme nom~valeur. Cette même notation est utilisée pour l’affectation nom ~ valeur.

Les paramètres de fonction peuvent avoir une valeur par défaut (param~expression) et des paramètres nommés uniquement (*param ou *param~defaut). Les paramètres positionnels sans valeur par défaut doivent précéder ceux qui en ont une.

3. Valeurs et types

Les valeurs documentées par l’interpréteur comprennent : nombre normal, grand entier, texte, booléen, vecteur, matrice, liste, fonction et instance de classe.

Les constantes booléennes sont VRAI et FAUX. Les raccourcis V et F sont reconnus comme leurs équivalents.

pasdefini représente l’absence de valeur.

lettr et Lettr sont des vecteurs constants contenant respectivement les 26 lettres minuscules et majuscules.

Un grand entier est produit par entier(...) et est représenté séparément d’un nombre normal. est.enti(...) et est.reel(...) permettent de les distinguer.

4. Variables et portée

L’affectation utilise nom ~ valeur.

Les variables sont organisées en portées. Les fonctions normales utilisent une portée globale et une portée locale ; les fonctions anonymes capturent leur environnement de création (closure).

Les fonctions appelées ne voient pas automatiquement les variables locales de leurs appelantes : la résolution est lexicale, avec l’environnement capturé pour les fonctions anonymes.

Une variable contenant une fonction peut être appelée comme une fonction (f(5)). Une variable portant le même nom qu’une fonction ou classe peut masquer cette fonction/classe lors d’un appel direct.

5. Expressions et opérateurs

Le moteur possède un tokenizeur et un analyseur d’expressions dédiés ; le code utilisateur n’est pas exécuté avec eval JavaScript.

L’ordre de traitement implémenté est : ou, et, dan, comparaisons, +/-, opérateurs multiplicatifs, :, unaire -, puissance ^, puis appels/indices/accès aux attributs.

Les opérations vectorielles et matricielles utilisent un recyclage lorsque l’opération le prévoit. Les dimensions doivent respecter les règles propres à chaque opération.

6. Contrôle du flux

si, sinon si et sinon forment les structures conditionnelles par blocs.

sision(...) est la forme fonctionnelle/vectorisée du choix conditionnel.

pou(...) possède une forme numérique et une forme pou(var dan objet) pour parcourir un vecteur.

tanqer(condition){...} répète tant que la condition est vraie. tanqer VRAI{...} et tanqer V{...} fournissent le raccourci de boucle infinie.

stop quitte la boucle courante et continu passe à l’itération suivante.

Le pas de pou ne peut pas être 0 afin d’éviter une boucle infinie.

La profondeur des appels de fonctions est protégée par limiteRecursion() ; la valeur par défaut actuelle est 500 appels imbriqués.

7. Fonctions

Une fonction nommée se déclare avec fonc nom(parametres){...}.

retour valeur termine la fonction et renvoie une valeur. retour ou retour() sans valeur renvoie pasdefini.

Les arguments peuvent être positionnels ou nommés (param~valeur). Les paramètres peuvent avoir une valeur par défaut.

Une fonction peut être passée comme valeur, reçue comme paramètre, renvoyée par retour ou appelée via une variable.

Une fonction anonyme peut être créée avec la forme fonc(parametres) expression. Elle capture l’environnement actif lors de sa création.

8. Classes et objets

Une classe se déclare avec classe NomClasse { ... }, éventuellement herite Parent.

init(moi, ...) est le constructeur lorsqu’il existe. moi désigne l’instance courante et doit être le premier paramètre des méthodes.

Les attributs d’instance se lisent et s’écrivent avec objet.attribut et objet.attribut ~ valeur.

Les attributs déclarés directement dans le corps de la classe, hors méthode, sont des attributs partagés : une seule valeur par classe, accessibles par NomClasse.attribut.

L’héritage recherche les méthodes et attributs partagés dans la chaîne des classes parentes. Une méthode redéfinie dans l’enfant est prioritaire.

parent.methode(moi, ...) appelle la version définie par la classe parente.

est.instance(objet, NomClasse) reconnaît aussi une instance d’une sous-classe de NomClasse.

9. Collections, vecteurs et matrices

c(...) construit un vecteur en aplatissant les vecteurs/matrices fournis et en unifiant leur type.

liste(...) conserve des éléments hétérogènes sans les aplatir.

seq, rep, alea, ralea et debut:fin permettent de construire ou générer des suites/vecteurs.

matrice(...) construit une matrice avec nlig, ncol et parlig ; le remplissage par défaut est colonne par colonne.

trans(m) transpose une matrice.

Les indices de vecteurs/matrices utilisent une base 1. Les sélections multiples, indices logiques et modifications par indexation sont pris en charge.

10. Texte

Un texte littéral utilise |...|.

texte(...) construit une seule valeur texte à partir de plusieurs éléments sans l’afficher.

var.miniscul(), var.majuscul() et var.suprespac() sont des méthodes texte chaînables.

saulig représente un saut de ligne et peut être utilisé comme argument autonome dans plusieurs fonctions de construction/affichage.

11. Entrées et sorties

affi(...) affiche des textes et des expressions.

entr(...) affiche un message puis attend une saisie et convertit automatiquement en nombre lorsque c’est possible.

Les variantes entr.secret, entr.nombr, entr.text, entr.oui, entr.Nsecret et entr.Tsecret spécialisent la saisie.

effa() efface la console ; effa(nom...) supprime des variables de la mémoire. voi() inspecte les éléments en mémoire.

12. Sauvegarde et fichiers MLD

ecrire et lire sauvegardent/récupèrent des valeurs dans le stockage interne de l’application.

ecrire.fichier, lire.fichier, existe.fichier, ajout.fichier, ajout.Tfichier, voir.fichier et supri.fichier travaillent avec de vrais fichiers lorsque l’application native est installée.

Les sauvegardes de données sont sérialisées en JSON dans les fichiers .mld.

Les opérations de chemin direct et certaines opérations natives nécessitent l’application Android installée et le pont natif fourni par le projet.

13. Graphiques

trac(...) trace une courbe dans la console sous forme de canvas.

grille() active la grille du dernier graphique et grille(FAUX) la désactive.

Les options de trac comprennent notamment couleur, type, titre, xlab et ylab.

14. Gestion des erreurs

essai{...} attrape{...} intercepte les erreurs du bloc essai.

attrape(msg){...} place le message d’erreur dans la variable msg. attrape(msg, code){...} place en plus un code d’erreur dans la variable code, pour distinguer la cause sans avoir à comparer le texte du message.

Les codes d’erreur sont des constantes du langage (comme VRAI/FAUX) : ils s’écrivent directement, sans texte entre guillemets : les textes utilisent |...| (ex. si(code==DIVISION_ZERO){...}). Plusieurs codes peuvent être combinés avec l’opérateur ou : si(code==FICHIER_INTROUVABLE ou code==CLE_INTROUVABLE){...}.

Codes d’erreur reconnus : DIVISION_ZERO, FICHIER_INTROUVABLE, FICHIER_DEJA_EXISTANT, FICHIER_INVALIDE, CLE_INTROUVABLE, VARIABLE_INCONNUE, FONCTION_INCONNUE, ATTRIBUT_INCONNU, INDEX_HORS_LIMITE, TYPE_INVALIDE, RECURSION_MAX, PERMISSION_REFUSEE, INDISPONIBLE_HORS_APP. Toute autre erreur (syntaxe, mauvais nombre/type d’argument, structure mal formée...) reçoit le code générique SYNTAXE (également disponible comme constante).

retour, stop et continu sont des signaux de contrôle et ne sont pas transformés en erreurs ordinaires par essai/attrape.

15. Base et résolution des noms

base.nom(...) force l’appel de la fonction intégrée nom, même lorsqu’une fonction utilisateur porte le même nom.

Une fonction utilisateur, une classe ou une variable-fonction peut masquer une fonction intégrée lors d’un appel direct, conformément aux règles de résolution de l’interpréteur.

Les constantes VRAI, FAUX, V, F, pasdefini, lettr et Lettr ne sont pas des fonctions et s’écrivent sans parenthèses.

16. Extensions de fichiers

.mlg : code source MonLangage.

.mld : données/sauvegardes MonLangage.

L’éditeur de ce projet ouvre et enregistre les sources avec l’extension .mlg. Le workflow Android associe également les fichiers .mlg à l’application.

17. Documentation intégrée

aide() affiche les commandes regroupées par catégorie.

aide(nomOuSymbole) affiche la documentation ciblée d’une commande ou d’un symbole.

aide(spec) ouvre l’écran dédié de la spécification officielle complète.

La présente page est embarquée dans www/SPECIFICATION.html, donc disponible hors ligne dans l’APK Capacitor.

18. Référence complète des commandes et symboles

Base

affi

affi(...)
  • Affiche du texte litteral lorsque le texte est entre |...|.
  • Affiche aussi la valeur d'une expression (variable, calcul, vecteur, matrice...).
  • Dans affi(), chaque element a afficher est separe par une virgule (,).
Voir l’exemple
affi(|Resultat :|, 2+2)   ->   affiche : Resultat : 4

entr

entr(...)
  • Affiche le message entre |...| puis attend que l'utilisateur tape une reponse.
  • Comme affi(), plusieurs elements separes par une virgule (,) peuvent etre combines dans le message.
  • Renvoie ce que l'utilisateur a tape.
  • Convertit automatiquement en nombre si possible, sinon renvoie du texte.
Voir l’exemple
age ~ entr(|Quel age as-tu, |, prenom, |?|)

entr.secret

entr.secret(|texte|, sty~|*|)
  • Comme entr(), mais la frappe n'est jamais affichee en clair (utile pour un mot de passe ou un code PIN).
  • Sans sty~... : rien n'est affiche du tout pendant la frappe (pas meme un caractere de masquage).
  • Avec sty~... : affiche ce caractere (choisi par le codeur, ex: |*| ou |.|) autant de fois que de caracteres deja tapes.
  • Convertit automatiquement en nombre si possible, sinon renvoie du texte (comme entr()).
Voir l’exemple
pin ~ entr.secret(|Code secret:|, sty~|*|)
secret ~ entr.secret(|Mot de passe:|)   ** rien affiche du tout **

entr.nombr

entr.nombr(...)
  • Comme entr(), mais sans masquer la frappe : redemande automatiquement en boucle tant que la saisie n'est pas un nombre valide.
  • Renvoie toujours un nombre.
Voir l’exemple
montant ~ entr.nombr(|Montant:|)

entr.text

entr.text(...)
  • Comme entr(), mais sans masquer la frappe et sans jamais convertir en nombre : renvoie toujours du texte tel quel.
  • Utile pour un code avec des zeros en tete (ex: |0123|), qui deviendrait sinon le nombre 123 avec entr().
Voir l’exemple
code ~ entr.text(|Code postal:|)

entr.oui

entr.oui(...)
  • Question fermee oui/non : redemande en boucle tant que la reponse n'est pas reconnue.
  • Accepte oui/o/ok/non/n, insensible a la casse et aux espaces.
  • Renvoie directement VRAI ou FAUX, pas besoin de comparer le texte tape.
Voir l’exemple
si(entr.oui(|Confirmer le virement ?|)){ ... }

entr.Nsecret

entr.Nsecret(|texte|, sty~|*|)
  • entr.secret() + validation : redemande en boucle tant que la saisie masquee n'est pas un nombre valide.
  • Renvoie toujours un nombre.
Voir l’exemple
pin ~ entr.Nsecret(|Code (4 chiffres):|, sty~|*|)

entr.Tsecret

entr.Tsecret(|texte|, sty~|*|)
  • entr.secret(), mais renvoie TOUJOURS du texte, jamais converti en nombre.
  • Utile pour un code avec des zeros en tete (ex: |0123|), qui deviendrait sinon le nombre 123.
Voir l’exemple
code ~ entr.Tsecret(|Code:|, sty~|*|)

Sauvegarde

ecrire

ecrire(cle, valeur) ou ecrire(cle, val1, val2, ...)
  • Sauvegarde silencieuse et immediate : reste dans l'app, aucune interaction utilisateur.
  • N'importe quelle valeur peut etre sauvegardee : nombre, texte, booleen, vecteur, matrice, liste, instance de classe.
  • Avec plusieurs valeurs, elles sont regroupees et sauvegardees comme une liste() (types conserves, pas de fusion).
  • cle doit etre du texte. Ecraser une cle deja utilisee remplace l'ancienne sauvegarde.
Voir l’exemple
ecrire(|mon_compte|, moi)
ecrire(|scores|, 12, |bravo|, VRAI)   ** sauvegarde une liste() **

lire

lire(cle)
  • Recupere une valeur sauvegardee avec ecrire(...).
  • Renvoie pasdefini si la cle n'existe pas.
Voir l’exemple
c ~ lire(|mon_compte|)

ecrire.fichier

ecrire.fichier(nom, valeur, ecra~FAUX) ou ecrire.fichier(chemin, val1, val2, ..., ecra~FAUX)
  • ecrire.fichier(nom, valeur) : ouvre le navigateur de fichiers integre pour choisir ou enregistrer un vrai fichier .mld.
  • ecrire.fichier(chemin, valeur) : si nom contient un '/', ecriture DIRECTE a cet emplacement, sans rien afficher a l'ecran.
  • Avec plusieurs valeurs, elles sont regroupees comme une liste() (meme regle que ecrire()).
  • ecra~FAUX par defaut : si le fichier existe deja, l'ecriture est REFUSEE (erreur, a intercepter avec essai/attrape). ecra~VRAI ecrase sans verifier.
  • Le chemin direct et la verification ecra ne fonctionnent que dans l'app installee (pas en previsualisation navigateur).
  • Contrairement a ecrire(), le fichier peut ensuite etre partage, copie, deplace hors de l'app.
Voir l’exemple
ecrire.fichier(|sauvegarde_banque|, moi, ecra~VRAI)
si(existe.fichier(|/storage/emulated/0/Download/banque.mld|)) { affi(|deja present|) }
sinon { ecrire.fichier(|/storage/emulated/0/Download/banque.mld|, moi) }

existe.fichier

existe.fichier(chemin)
  • Renvoie VRAI si un fichier existe deja a ce CHEMIN COMPLET (avec '/'), FAUX sinon.
  • A utiliser typiquement avant ecrire.fichier(chemin, valeur) pour decider d'ecraser ou non.
  • Disponible uniquement dans l'app installee (pas en previsualisation navigateur).
Voir l’exemple
si(existe.fichier(|/storage/emulated/0/Download/banque.mld|)) { affi(|Fichier deja present|) }

lire.fichier

lire.fichier() ou lire.fichier(chemin)
  • lire.fichier() : ouvre le navigateur de fichiers du telephone et attend que l'utilisateur choisisse un fichier sauvegarde avec ecrire.fichier(...).
  • lire.fichier(chemin) : lit DIRECTEMENT le fichier a ce chemin, sans rien afficher a l'ecran.
  • Le chemin direct ne fonctionne que dans l'app installee (pas en previsualisation navigateur).
  • Renvoie la valeur sauvegardee dans ce fichier.
Voir l’exemple
c ~ lire.fichier()
c ~ lire.fichier(|/storage/emulated/0/Download/banque.mld|)

ajout

ajout(cle, valeur, ...)
  • Ajoute une ou plusieurs valeurs a une cle DEJA SAUVEGARDEE avec ecrire(...), sans rien ecraser.
  • Erreur si la cle n'existe pas encore : utiliser ecrire(...) pour la creer d'abord.
  • Si la cle contient un vecteur, il est etendu directement (comme .ajout() dessus), sans devenir une liste().
  • Si la cle contient deja une liste(), les nouvelles valeurs s'y ajoutent simplement.
  • Sinon (nombre, texte, booleen, matrice, instance), l'ancienne valeur devient le premier element d'une nouvelle liste().
Voir l’exemple
ecrire(|notes|, c(12,15))
ajout(|notes|, 9, 18)   ** notes reste un vecteur : 12 15 9 18 **
ecrire(|score|, 12)
ajout(|score|, 15, 9)   ** score devient une liste() : 12, 15, 9 **

ajout.fichier

ajout.fichier(nom, valeur, ...) ou ajout.fichier(chemin, valeur, ...)
  • Ajoute une ou plusieurs valeurs a un fichier DEJA SAUVEGARDE avec ecrire.fichier(...), sans l'ecraser.
  • ajout.fichier(nom, ...) : ouvre le navigateur de fichiers integre pour choisir le fichier existant a completer.
  • ajout.fichier(chemin, ...) : si nom contient un '/', le fichier doit deja exister exactement a cet emplacement.
  • Meme logique de fusion que ajout(cle, ...) ci-dessus.
  • Disponible uniquement dans l'app installee (pas de repli en previsualisation navigateur, contrairement a ecrire.fichier()).
Voir l’exemple
ajout.fichier(|/storage/emulated/0/Download/scores.mld|, 15, 9)

ajout.Tfichier

ajout.Tfichier(nom, valeur, ...) ou ajout.Tfichier(chemin, valeur, ...)
  • Variante de ajout.fichier(...) reservee aux fichiers dont le contenu sauvegarde est du TEXTE (cree avec ecrire.fichier(chemin, |...|)).
  • Concatene directement le texte a la suite de l'existant (comme le ferait toi-meme lire.fichier()+concatenation+ecrire.fichier(ecra~VRAI)), sans jamais transformer le contenu en liste().
  • ajout.fichier(...) classique ne sait pas faire ca : sur un texte, il transforme l'existant en 1er element d'une liste() au lieu de le prolonger -- ajout.Tfichier() comble ce cas precis.
  • Erreur si le fichier n'existe pas encore, ou si son contenu sauvegarde n'est pas du texte (utiliser ajout.fichier() dans ce cas).
  • Meme regle nom/chemin que ajout.fichier(...) : sans '/' ouvre le navigateur integre, avec '/' chemin direct.
Voir l’exemple
ecrire.fichier(|/sdcard/historique.mld|, ||)
ajout.Tfichier(|/sdcard/historique.mld|, texte(|# Depot: |, 500, saulig))

voir.cle

voir.cle()
  • Renvoie un vecteur avec les NOMS de toutes les cles actuellement sauvegardees avec ecrire(...) (pas leur contenu).
  • Permet de savoir ce qui existe sans devoir tout effacer via 'Effacer donnees utilisateur' de l'app (qui vide TOUTES les cles a la fois).
  • Vecteur vide si aucune cle n'est sauvegardee.
Voir l’exemple
affi(voir.cle())

supri.cle

supri.cle(cle)
  • Supprime UNE cle precise sauvegardee avec ecrire(...), sans toucher aux autres.
  • Erreur si la cle n'existe pas -- verifiable avant avec voir.cle().
Voir l’exemple
supri.cle(|scores|)

voir.fichier

voir.fichier() ou voir.fichier(dossier)
  • Renvoie un vecteur avec les NOMS des fichiers .mld presents dans un dossier (pas leur contenu).
  • Sans argument, utilise le dossier racine du stockage de l'appareil.
  • L'app ne tient pas de registre central de tous les fichiers crees avec ecrire.fichier() (ils peuvent etre ecrits a n'importe quel chemin) : voir.fichier() liste le contenu d'UN dossier donne, comme le navigateur de fichiers integre.
  • Disponible uniquement dans l'app installee (pas en previsualisation navigateur).
Voir l’exemple
affi(voir.fichier(|/storage/emulated/0/Download|))

supri.fichier

supri.fichier(nom) ou supri.fichier(chemin)
  • Supprime UN fichier precis, sans toucher aux autres.
  • Sans '/' : ouvre le navigateur de fichiers integre en mode 'ouvrir' pour choisir le fichier a supprimer.
  • Avec un chemin complet (avec '/') : suppression DIRECTE a cet emplacement, sans rien afficher a l'ecran -- erreur si le fichier n'existe pas (verifiable avant avec existe.fichier(...)).
  • Disponible uniquement dans l'app installee (pas en previsualisation navigateur).
Voir l’exemple
supri.fichier(|/storage/emulated/0/Download/scores.mld|)

Base

~

nom ~ valeur
  • Cree la variable si elle n'existe pas encore.
  • Remplace sa valeur si elle existe deja.
  • A gauche : le nom de la variable. A droite : la valeur ou l'expression a calculer.
Voir l’exemple
x ~ 5 + 3   ->   x vaut maintenant 8

base

base.nom(...)
  • Force l'utilisation de la version d'origine (native) d'une commande avec le prefixe base.
  • Exemple : base.affi(...), base.aide(), base.sin(...).
  • Utile si tu as defini ta propre fonction avec le meme nom qu'une commande du langage, car elle la masquerait sinon.
  • Les methodes de variable comme var.miniscul(), var.majuscul() et var.suprespac() restent attachees a la variable et ne se remplacent pas par base.var... .
Voir l’exemple
fonc affi(x){ ... }
affi(1)         ->  utilise TA fonction
base.affi(1)    ->  utilise l'affi() d'origine

aide

aide() ou aide(nomOuSymbole) ou aide(spec)
  • aide() : affiche la liste de toutes les commandes, grouper par categorie.
  • aide(nomOuSymbole) : affiche seulement l'explication de cette commande ou de ce symbole.
  • aide(spec) : ouvre l'ecran de la specification officielle complete de MonLangage.
Voir l’exemple
aide(matrice)   ou   aide(+)
aide(spec)   ->   ouvre la specification officielle

natu

natu(var)
  • Renvoie la nature (le type) de l'objet contenu dans var, sous forme de texte.
  • Valeurs possibles : |texte|, |nombre|, |booleen|, |vecteur| ou |matrice|.
  • Pour une instance de classe, renvoie le nom de sa classe (comme type(objet).__name__ en Python) : par exemple |Chien|.
Voir l’exemple
natu(3)          ->   nombre
natu(|bonjour|)  ->   texte
natu(VRAI)       ->   booleen
natu(c(1,2,3))   ->   vecteur
classe Chien{}
a ~ Chien()
natu(a)          ->   Chien

entier · reel

entier(x) / reel(x)
  • Convertit x vers un GRAND ENTIER exact ou vers un nombre normal (reel), comme int(...)/float(...) en Python.
  • entier(x) : grand entier exact (precision illimitee, contrairement aux nombres normaux limites a 2^53), tronque une valeur a virgule vers zero. Depuis un texte, doit etre une suite de chiffres valide.
  • reel(x) : nombre normal (flottant) ; depuis un grand entier, peut perdre en precision au-dela de 2^53.
  • Voir aussi est.enti(...)/est.reel(...) pour verifier le type, natu(...) pour l'obtenir en texte.
Voir l’exemple
entier(2) ^ entier(100)   ->   1267650600228229401496703205376  (exact)
reel(entier(5))            ->   5

conver.nombr · conver.text · conver.vecteu · conver.matric

conver.nombr(var) / conver.text(var) / conver.vecteu(var) / conver.matric(var)
  • Convertit var vers un autre type.
  • conver.nombr(var) : convertit en nombre (un texte comme |3.5| devient 3.5 ; VRAI/FAUX deviennent 1/0). Erreur si le texte n'est pas un nombre valide.
  • conver.text(var) : convertit en texte (un nombre ou un booleen devient sa version texte, ex: VRAI -> |VRAI|).
  • conver.vecteu(var) : convertit en vecteur. Une matrice devient un vecteur de tous ses elements. Un nombre/texte/booleen devient un vecteur a 1 element.
  • conver.matric(var) : convertit en matrice. Un vecteur devient une matrice a 1 colonne. Un nombre/texte/booleen devient une matrice 1x1.
Voir l’exemple
conver.nombr(|3.5|)   ->   3.5
conver.text(42)       ->   |42|
conver.vecteu(matrice(1:4, nlig~2, ncol~2))   ->   c(1,2,3,4)
conver.matric(c(1,2,3))   ->   matrice 3x1

est.nombr · est.text · est.vecteu · est.matric · est.enti · est.reel · est.liste

est.nombr(var) / est.text(var) / est.vecteu(var) / est.matric(var) / est.enti(var) / est.reel(var) / est.liste(var)
  • Verifie le type de var, et renvoie VRAI ou FAUX.
  • est.nombr(var) : VRAI si var est un nombre normal OU un grand entier (large ; voir est.enti/est.reel pour distinguer precisement).
  • est.text(var) : VRAI si var est un texte.
  • est.vecteu(var) : VRAI si var est un vecteur.
  • est.matric(var) : VRAI si var est une matrice.
  • est.enti(var) : VRAI uniquement si var est un GRAND ENTIER (cree via entier(...)) ; FAUX pour un nombre normal meme de valeur entiere.
  • est.reel(var) : VRAI uniquement si var est un nombre normal (reel) ; FAUX pour un grand entier.
  • est.liste(var) : VRAI si var est une liste (creee via liste(...)).
Voir l’exemple
est.nombr(3)        ->   VRAI
est.text(|bonjour|) ->   VRAI
est.vecteu(c(1,2))  ->   VRAI
est.enti(entier(3)) ->   VRAI
est.reel(3)          ->   VRAI
est.reel(entier(3)) ->   FAUX
est.liste(liste(1,2)) ->   VRAI
si(est.nombr(x)){ affi(|x est un nombre|) }

est.fonction

est.fonction(var)
  • VRAI si var contient une fonction (recue en parametre, ou stockee avec f ~ nomFonction).
  • Une fonction perso deja declaree (fonc nom(...){...}) peut etre utilisee comme une valeur : stockee dans une variable (f ~ doubler), passee en argument a une autre fonction, ou renvoyee avec retour.
  • Une fois stockee, elle s'appelle comme n'importe quelle fonction : f(5).
  • Les fonctions peuvent aussi etre creees anonymement dans une expression avec la forme fonc(parametres) expression, puis stockees, passees en argument ou renvoyees.
Voir l’exemple
fonc doubler(x){ retour x * 2 }
f ~ doubler
affi(f(5))          ->   10
affi(est.fonction(f))   ->   VRAI

fonc mapper(vecteur, f){
    resultat ~ c()
    pou(x dan vecteur){ resultat.ajout(f(x)) }
    retour resultat
}
affi(mapper(c(1,2,3), doubler))   ->   2 4 6

est.instance

est.instance(objet, NomClasse)
  • Verifie si objet est une instance de la classe NomClasse (comme isinstance(...) en Python).
  • Renvoie aussi VRAI si objet est une instance d'une classe qui HERITE de NomClasse.
  • NomClasse s'ecrit tel quel (sans les deux barres verticales), comme un nom de classe, pas une variable.
Voir l’exemple
classe Animal { }
classe Chien herite Animal { }
c ~ Chien()
est.instance(c, Chien)   ->   VRAI
est.instance(c, Animal)  ->   VRAI (heritage)

**

** commentaire
  • Tout ce qui suit ** jusqu'a la fin de la ligne est un commentaire : ignore par le programme.
  • Utile pour expliquer ton code sans que ca soit execute.
  • Un ** a l'interieur d'un texte litteral |...| n'est pas traite comme un commentaire.
Voir l’exemple
x ~ 5 ** on initialise x a 5
** ceci est une ligne entierement en commentaire

Controle

pou

pou(var, debut, fin, pas){ ... } / pou(var dan objet){ ... }
  • Repete le bloc entre accolades. Deux syntaxes possibles.
  • 1) pou(var, debut, fin, pas) : var prend d'abord la valeur debut, puis debut+pas, et ainsi de suite jusqu'a fin (fin incluse). pas est facultatif : vaut 1 par defaut, et peut etre negatif (pour compter a l'envers).
  • debut, fin et pas peuvent etre des expressions complexes (avec des parentheses, ^, des appels de fonction, etc.), separees par des virgules.
  • 2) pou(var dan objet) : var prend tour a tour chaque valeur de objet, qui doit etre un vecteur.
  • stop permet d'arreter la boucle avant la fin (voir aide(stop)).
Voir l’exemple
pou(i, 1, 5){ affi(i) }   ->   affiche 1 2 3 4 5
pou(i, 10, 1, -1){ affi(i) }   ->   compte a l'envers de 10 a 1
pou(x dan c(3,7,9)){ affi(x) }   ->   affiche 3 7 9

stop

stop
  • Arrete immediatement la boucle (pou ou tanqer) en cours, et continue l'execution juste apres cette boucle.
  • Utilisable a l'interieur d'un pou(...){...} ou d'un tanqer(...){...}, y compris a l'interieur d'un si(...) place dans la boucle.
Voir l’exemple
pou(i, 1, 10){
  si(i==4){ stop }
  affi(i)
}   ->   affiche 1 2 3

continu

continu
  • Interrompt uniquement le tour en cours de la boucle (pou ou tanqer), et passe directement au tour suivant : le reste du bloc est saute pour ce tour, mais la boucle continue.
  • Contrairement a stop, ca ne quitte pas la boucle.
  • Utilisable a l'interieur d'un pou(...){...} ou d'un tanqer(...){...}, y compris a l'interieur d'un si(...) place dans la boucle.
Voir l’exemple
pou(i, 1, 5){
  si(i==3){ continu }
  affi(i)
}   ->   affiche 1 2 4 5

tanqer

tanqer(condition){ ... } / tanqer VRAI{ ... }
  • Repete le bloc tant que la condition reste vraie.
  • S'arrete des que la condition devient fausse (ou plus tot si stop est rencontre).
  • tanqer VRAI{...} (ou tanqer V{...}) : raccourci sans parentheses pour une boucle infinie, comme while True en Python. Pas besoin d'ecrire une condition bidon toujours vraie.
Voir l’exemple
x ~ 0
tanqer(x<5){ x ~ x+1 }

i ~ 0
tanqer VRAI{
  i ~ i+1
  si(i>=3){ stop }
}

si

si(condition){ ... }
  • Execute le bloc uniquement si la condition est vraie. Fonctionne comme if() en R.
  • Peut etre suivi de sinon si(...){...} et/ou d'un sinon final (tous optionnels).
Voir l’exemple
si(note>=10){ affi(|Reussi|) }

sinon

sinon{ ... }
  • Execute son bloc uniquement quand aucune condition precedente (si ou sinon si) n'etait vraie. Fonctionne comme else en R.
  • Un seul bloc au total est execute parmi si/sinon si/sinon : le premier dont la condition est vraie.
  • Toujours place juste apres un si(...){...} ou un sinon si(...){...}, jamais seul.
Voir l’exemple
si(note>=10){ affi(|Reussi|) } sinon{ affi(|Echoue|) }

sinon si

sinon si(condition){ ... }
  • Ajoute une condition supplementaire apres un si(...) (ou un autre sinon si), comme else if en R.
  • On peut en enchainer plusieurs a la suite d'un si(...).
  • Un seul bloc au total est execute parmi si/sinon si/sinon : le premier dont la condition est vraie.
  • Peut etre suivi d'autres sinon si(...){...} et/ou d'un sinon final (tous optionnels).
Voir l’exemple
si(note>=16){ affi(|Excellent|) } sinon si(note>=10){ affi(|Reussi|) } sinon{ affi(|Echoue|) }

sision

sision(condition, valeurSiVrai, valeurSiFaux)
  • Version vectorisee (element par element) de si/sinon, comme ifelse() en R.
  • condition peut etre un vecteur de tests (ex: x>0) : le resultat est un vecteur ou chaque element vient de valeurSiVrai ou valeurSiFaux selon le test correspondant.
  • valeurSiVrai et valeurSiFaux peuvent etre des scalaires ou des vecteurs (recycles si plus courts que condition, comme les autres operations vectorielles).
  • Si condition est un simple scalaire, renvoie directement valeurSiVrai ou valeurSiFaux.
Voir l’exemple
x ~ seq(-2,2,1)
affi(sision(x>=0, x, x*-1))   ->   [1] 2 1 0 1 2

essai · attrape

essai{ ... } attrape(msg, code){ ... } / essai{ ... } attrape(msg){ ... } / essai{ ... } attrape{ ... }
  • Intercepte une erreur levee dans le bloc essai au lieu de planter tout le script.
  • Si une erreur survient dans essai, l'execution du bloc s'arrete et le bloc attrape s'execute a la place.
  • Si aucune erreur ne survient, le bloc attrape est entierement ignore.
  • attrape(msg){...} recupere le message d'erreur (texte) dans la variable msg. attrape{...} (sans parametre) l'ignore.
  • attrape(msg, code){...} recupere en plus un code d'erreur dans la variable code, pour reagir differemment selon la cause sans comparer le texte du message.
  • Les codes sont des CONSTANTES du langage (comme VRAI/FAUX) : ils s'ecrivent sans les deux barres verticales (|...|), ex. si(code==DIVISION_ZERO){...}. Plusieurs codes se combinent avec l'operateur ou : si(code==FICHIER_INTROUVABLE ou code==CLE_INTROUVABLE){...}.
  • Codes reconnus : DIVISION_ZERO, FICHIER_INTROUVABLE, FICHIER_DEJA_EXISTANT, FICHIER_INVALIDE, CLE_INTROUVABLE, VARIABLE_INCONNUE, FONCTION_INCONNUE, ATTRIBUT_INCONNU, INDEX_HORS_LIMITE, TYPE_INVALIDE, RECURSION_MAX, PERMISSION_REFUSEE, INDISPONIBLE_HORS_APP. Toute autre erreur (syntaxe, arguments...) recoit le code generique SYNTAXE (egalement disponible comme constante).
  • Toujours place juste apres un essai{...}, jamais seul.
  • Ne peut pas empecher un arret manuel du script (bouton Retour pendant l'execution) : cela remonte toujours en dehors de essai/attrape.
Voir l’exemple
essai {\n    ecrire.fichier(|/storage/emulated/0/Download/save.mld|, moi, ecra~FAUX)\n} attrape(msg, code) {\n    si(code == FICHIER_DEJA_EXISTANT){ affi(|Deja sauvegarde|) }\n    sinon si(code == PERMISSION_REFUSEE){ affi(|Autorise le stockage dans les reglages|) }\n    sinon{ affi(|Echec de sauvegarde :|, msg) }\n}

limiteRecursion

limiteRecursion() / limiteRecursion(n)
  • Lit ou change la limite d'appels de fonction imbriques autorises (protection contre une recursion infinie), comme sys.setrecursionlimit(...) en Python.
  • limiteRecursion() sans argument : lecture seule, renvoie la limite actuelle (500 par defaut).
  • limiteRecursion(n) : change la limite a n et renvoie l'ANCIENNE valeur (pratique pour la restaurer ensuite).
  • Refuse un nombre non entier ou <= 0, ou une valeur inferieure a la profondeur d'appel actuelle.
  • Se reinitialise a 500 a chaque nouvelle execution du script.
Voir l’exemple
ancienne ~ limiteRecursion(2000)
** ... code qui a besoin de plus de profondeur ... **
limiteRecursion(ancienne)

fonc

fonc nom(param1, param2){ ... }
  • Definit une fonction reutilisable, avec un nom et des parametres.
  • Le bloc entre accolades s'execute a chaque appel de la fonction.
Voir l’exemple
fonc carre(x){ retour x*x }
affi(carre(5))   ->   25

retour

retour valeur
  • Arrete l'execution de la fonction et renvoie la valeur donnee comme resultat de l'appel.
  • La valeur renvoyee peut etre un nombre, mais aussi un vecteur ou une matrice (comme en R).
  • Utilisable uniquement a l'interieur d'une fonction (fonc).
Voir l’exemple
fonc double(x){ retour x*2 }
fonc doubleVecteur(v){ retour(v*2) }
affi(doubleVecteur(c(1,2,3)))   ->   2 4 6

classe

classe NomClasse [herite NomParent] { fonc init(moi, ...){...} fonc methode(moi, ...){...} }
  • Definit une classe (comme class en Python) : un modele pour creer des objets (instances).
  • init(moi, ...) est le constructeur, appele automatiquement a la creation d'une instance.
  • Chaque methode doit prendre moi comme premier parametre (comme self en Python).
  • Instanciation : a ~ NomClasse(arguments). Attribut : moi.nom ~ valeur (ecriture), a.nom (lecture). Methode : a.methode(...).
  • herite NomParent (facultatif) fait heriter de toutes les methodes de NomParent, voir herite.
Voir l’exemple
classe Animal {
    fonc init(moi, nom){ moi.nom ~ nom }
    fonc parler(moi){ affi(moi.nom, |fait un bruit.|) }
}
a ~ Animal(|Rex|)
a.parler()

attribut partage

classe NomClasse { attribut ~ valeur ... } puis NomClasse.attribut
  • Un attribut declare directement dans le corps de la classe (hors de toute methode) est PARTAGE par toutes les instances : une seule valeur pour toute la classe, pas une copie par instance.
  • S'initialise une seule fois, au demarrage du script (pas a chaque instanciation).
  • Se lit et se modifie avec NomClasse.attribut (le nom de la CLASSE, pas moi ni une instance) : NomClasse.attribut ~ nouvelleValeur.
  • Utile pour un compteur global, un reglage ou une valeur par defaut commune a toutes les instances.
Voir l’exemple
classe Voiture {
    compteurVentes ~ 0
    fonc init(moi, modele){
        moi.modele ~ modele
        Voiture.compteurVentes ~ Voiture.compteurVentes + 1
    }
}
v1 ~ Voiture(|Clio|)
v2 ~ Voiture(|208|)
affi(Voiture.compteurVentes)   ->   2

herite

classe Enfant herite Parent { ... }
  • Fait heriter une classe d'une autre (comme class Enfant(Parent): en Python).
  • La classe enfant recoit automatiquement toutes les methodes de la classe parente (y compris init).
  • Une methode redefinie dans l'enfant remplace celle du parent (elle est prioritaire).
  • Si l'enfant ne redefinit pas une methode, celle du parent est utilisee automatiquement.
Voir l’exemple
classe Animal {
    fonc init(moi, nom){ moi.nom ~ nom }
    fonc parler(moi){ affi(moi.nom, |fait un bruit.|) }
}
classe Chien herite Animal {
    fonc parler(moi){ affi(moi.nom, |aboie.|) }
}
c ~ Chien(|Rex|)
c.parler()   ->   Rex aboie.

parent

parent.methode(moi, ...)
  • Appelle la version d'une methode definie par la classe PARENTE (equivalent de super().methode(...) en Python).
  • Utilisable uniquement a l'interieur d'une methode d'une classe qui herite d'une autre (herite).
  • moi doit toujours etre passe en premier argument, comme pour n'importe quel appel de methode.
  • Utile pour garder le comportement du parent tout en ajoutant quelque chose en plus, au lieu de tout reecrire.
Voir l’exemple
classe Animal {
    fonc parler(moi){ affi(moi.nom, |fait un bruit.|) }
}
classe Chien herite Animal {
    fonc parler(moi){
        parent.parler(moi)
        affi(|(en particulier : aboie)|)
    }
}

moi

moi
  • A l'interieur d'une methode de classe, designe l'instance elle-meme (comme self en Python).
  • Doit etre le premier parametre de chaque fonc declaree dans une classe.
  • moi.attribut lit ou (avec ~) ecrit un attribut de l'instance courante.
Voir l’exemple
classe Compteur {
    fonc init(moi){ moi.n ~ 0 }
    fonc plus1(moi){ moi.n ~ moi.n + 1 }
}

Creer un vecteur/une matrice

c

c(a, b, c, ...)
  • Construit un vecteur a partir des valeurs donnees.
  • Si on lui donne un vecteur ou une matrice en argument, il en reprend tous les elements.
  • Unifie tout vers un seul type (texte > nombre > booleen) : pas de melange de types, contrairement a liste().
Voir l’exemple
c(1,2,3)          ->   [1] 1 2 3
c(|a|,|b|)        ->   [1] |a| |b|

liste

liste(a, b, c, ...)
  • Construit une liste a partir des valeurs donnees, accessible par indice comme un vecteur (maliste[i]).
  • Contrairement a c(), ne fusionne pas les vecteurs/matrices/listes donnes en argument et n'unifie PAS les types : chaque element garde son type d'origine (nombre, texte, booleen, vecteur, instance...).
  • Ecriture indexee possible : maliste[i]~valeur (ou moi.maliste[i]~valeur pour un attribut).
  • maliste.ajout(...) et maliste.supri(...) fonctionnent comme sur un vecteur, sans fusion ni unification.
Voir l’exemple
l ~ liste(1, |bonjour|, VRAI, c(1,2,3))
affi(l[1])   ->   1
affi(l[2])   ->   bonjour
l[1] ~ |change|

seq

seq(debut, fin, pas)
  • Construit une suite de nombres, de debut a fin.
  • pas est facultatif : +1 par defaut (ou -1 si fin est plus petit que debut).
Voir l’exemple
seq(1,10,2)   ->   [1] 1 3 5 7 9

rep

rep(elements, nombre)
  • Repete des elements a la suite, nombre fois.
  • elements peut etre une seule valeur ou un vecteur entier.
Voir l’exemple
rep(c(1,2),3)   ->   [1] 1 2 1 2 1 2

alea

alea(var, x) ou alea(debut, fin, x)
  • alea(var, x) : choisit x elements au hasard, sans remise, parmi un vecteur ou une matrice.
  • alea(debut, fin, x) : choisit x nombres entiers au hasard, sans remise, dans l'intervalle [debut, fin] (bornes incluses).
  • Renvoie toujours un vecteur, meme pour x~1.
  • x ne peut pas depasser le nombre d'elements disponibles (pas de remise = jamais deux fois la meme valeur).
Voir l’exemple
alea(1,49,6)         ->   6 numeros distincts entre 1 et 49
alea(c(10,20,30),2)  ->   2 valeurs distinctes parmi le vecteur

ralea

ralea(var, x) ou ralea(debut, fin, x)
  • Comme alea(...), mais AVEC remise : un meme element/nombre peut sortir plusieurs fois.
  • x peut donc depasser le nombre d'elements disponibles (contrairement a alea()).
Voir l’exemple
ralea(1,6,10)          ->   10 lancers de de a 6 faces (repetitions possibles)
ralea(c(|pile|,|face|),5)  ->   5 tirages a pile ou face

:

debut:fin
  • Raccourci rapide pour creer une suite de nombres entiers, avec un pas de 1.
  • Si fin est plus petit que debut, compte a l'envers (pas de -1).
Voir l’exemple
1:5   ->   [1] 1 2 3 4 5
5:1   ->   [1] 5 4 3 2 1

lettr

lettr
  • Identifiant constant (sans parentheses, comme VRAI/FAUX) qui vaut un vecteur contenant les 26 lettres de l'alphabet, en minuscule, de |a| a |z|.
Voir l’exemple
lettr   ->   [1] |a| |b| |c| ... |z|
x ~ lettr
pou(l dan lettr){ affi(l) }

Lettr

Lettr
  • Identifiant constant (sans parentheses, comme VRAI/FAUX) qui vaut un vecteur contenant les 26 lettres de l'alphabet, en majuscule, de |A| a |Z|.
Voir l’exemple
Lettr   ->   [1] |A| |B| |C| ... |Z|

matrice

matrice(elements, nlig~..., ncol~..., parlig~VRAI ou FAUX)
  • Construit une matrice a partir d'une liste d'elements.
  • nlig et ncol : un seul des deux suffit, l'autre est calculer automatiquement.
  • parlig~VRAI remplit ligne par ligne. Par defaut (parlig~FAUX), le remplissage se fait colonne par colonne.
Voir l’exemple
matrice(1:6, nlig~2, ncol~3)

trans

trans(m)
  • Renvoie la transposee d'une matrice : les lignes deviennent des colonnes et inversement.
  • Une matrice nlig x ncol devient une matrice ncol x nlig.
Voir l’exemple
m ~ matrice(1:6, nlig~2, ncol~3)
trans(m)   ->   une matrice 3x2

Acceder / modifier un element

[ · ]

v[i] / m[ligne,colonne]
  • Lit un ou plusieurs elements d'un vecteur (v[i]) ou d'une matrice (m[ligne,colonne]).
  • Les indices commencent a 1 (pas a 0).
  • Un indice laisse vide signifie 'tout' : m[,2] = toute la colonne 2, m[3,] = toute la ligne 3.
  • L'indice peut aussi etre un vecteur d'indices (c(2,5) ou 2:4) pour en selectionner plusieurs a la fois.
  • L'indice peut etre un vecteur logique (issu d'une comparaison) pour selectionner selon une condition.
  • Peut aussi servir a modifier : v[2:4] ~ c(0,0,0), B[,4] ~ c(0,0,0), B[B>15] ~ 0, etc.
  • Agrandissement automatique : v[8] ~ x ou B[5,5] ~ x avec un indice au-dela de la taille actuelle etend le vecteur/la matrice, les nouvelles cases etant remplies de 0.
Voir l’exemple
v[2]         ->   2e element
v[2:4]       ->   du 2e au 4e element
v[c(2,5)]    ->   le 2e et le 5e element
v[v>3]       ->   les elements superieurs a 3
B[2:4,]      ->   les lignes 2 a 4, toutes les colonnes
B[,2:5]      ->   toutes les lignes, les colonnes 2 a 5
B[B==5]      ->   tous les elements de B qui valent 5
B[B>15] ~ 0  ->   remplace par 0 tous les elements > 15
v[7] ~ 9     ->   agrandit v a 7 elements (0 pour les cases vides) puis met 9 en 7e position

ajout

nom.ajout(elements)
  • Ajoute de nouveaux elements a un vecteur ou une matrice qui existe deja, sans supprimer ce qu'il contenait.
  • Pour une matrice, les elements sont ajoutes comme nouvelle(s) colonne(s).
Voir l’exemple
v.ajout(4,5)
m.ajout(9,9)

supri

nom.supri(elements)
  • Supprime des elements d'un vecteur ou d'une matrice qui existe deja (inverse de .ajout()).
  • Pour un vecteur : supprime, pour chaque valeur donnee, sa premiere occurrence trouvee.
  • Pour une matrice : les elements donnes (par groupe de nlig, comme pour .ajout()) doivent correspondre exactement a une colonne existante, qui est alors supprimee.
Voir l’exemple
v~c(2,3,2,5)
v.supri(2,3)     ->   reste c(2,5)
v~c(|rea|,|r|,|e|)
v.supri(|rea|)   ->   reste c(|r|,|e|)
v.supri(v[1])    ->   supprime la valeur en 1ere position

Operateurs

+

a + b
  • Additionne deux nombres, deux vecteurs (element par element) ou deux matrices (element par element, memes dimensions).
  • Un nombre seul est ajoute a chaque element si on l'additionne avec un vecteur ou une matrice.
Voir l’exemple
c(1,2,3) + c(10,20,30)   ->   [1] 11 22 33

-

a - b
  • Soustrait deux nombres, deux vecteurs ou deux matrices, meme principe que +.
Voir l’exemple
c(10,20,30) - c(1,2,3)   ->   [1] 9 18 27

*

a * b
  • Multiplie deux nombres.
  • Ne fonctionne pas encore sur les vecteurs/matrices (utilise . , × ou .. pour ceux-la).
Voir l’exemple
3 * 4   ->   12

/

a / b
  • Divise deux nombres.
Voir l’exemple
10 / 4   ->   2.5

%

a % b
  • Renvoie le reste de la division entiere de a par b.
Voir l’exemple
7 % 2   ->   1

.

v1 . v2
  • Calcule le produit scalaire entre deux vecteurs de meme taille.
  • Multiplie les elements un par un puis additionne le tout : le resultat est un seul nombre.
Voir l’exemple
c(1,2,3) . c(4,5,6)   ->   32

×

v1 × v2
  • Calcule le produit vectoriel entre deux vecteurs.
  • Fonctionne uniquement pour des vecteurs de taille 3 (comme en geometrie dans l'espace).
Voir l’exemple
c(1,0,0) × c(0,1,0)   ->   [1] 0 0 1

..

m1 .. m2
  • Multiplie deux matrices selon les regles du produit matriciel (pas element par element).
  • Le nombre de colonnes de m1 doit etre egal au nombre de lignes de m2.
Voir l’exemple
m1 .. m2

^

a ^ b
  • Puissance : a a la puissance b.
  • Fonctionne aussi element par element sur les vecteurs et les matrices, avec recyclage comme + et -.
Voir l’exemple
2 ^ 3   ->   8
c(1,2,3) ^ 2   ->   [1] 1 4 9

ENTI

a ENTI b
  • Division entiere : divise a par b et ne garde que la partie entiere (arrondi vers le bas).
  • Fonctionne aussi element par element sur les vecteurs et les matrices.
Voir l’exemple
7 ENTI 2   ->   3
c(7,9,11) ENTI 2   ->   [1] 3 4 5

MOD

a MOD b
  • Renvoie le reste de la division entiere de a par b (equivalent a %).
  • Fonctionne aussi element par element sur les vecteurs et les matrices.
Voir l’exemple
7 MOD 2   ->   1
c(7,9,11) MOD 2   ->   [1] 1 1 1

dan

var1 dan var2
  • Teste si var1 se trouve dans var2.
  • Si var2 est un vecteur ou une matrice : renvoie un vecteur/une matrice de VRAI/FAUX, un par position (comme %in% en R), pour reperer a quelle(s) position(s) var1 se trouve.
  • Si var2 est une suite de caracteres (texte) : renvoie un simple VRAI/FAUX selon que var1 apparait comme sous-chaine dans var2.
  • var1 doit etre une valeur simple (pas un vecteur/une matrice).
  • Utilise dans si(...), VRAI si var1 se trouve a au moins une position.
Voir l’exemple
2 dan c(2,3,4)   ->   [1] VRAI FAUX FAUX
|mot| dan |un mot|   ->   VRAI

== · != · < · > · <= · >=

a == b / a != b / a < b / a > b / a <= b / a >= b
  • Compare deux valeurs et renvoie VRAI ou FAUX.
  • == egalite, != difference, < strictement inferieur, > strictement superieur, <= inferieur ou egal, >= superieur ou egal.
  • Fonctionne aussi element par element sur les vecteurs et les matrices (renvoie alors un vecteur/une matrice de VRAI/FAUX), avec recyclage comme + et -.
Voir l’exemple
3 == 3   ->   VRAI
c(1,2,3) > 2   ->   [1] FAUX FAUX VRAI

et · ou

condition1 et condition2 / condition1 ou condition2
  • Combine deux conditions booleennes.
  • et : VRAI seulement si les deux conditions sont vraies.
  • ou : VRAI si au moins une des deux conditions est vraie.
  • Utilises typiquement dans si(...), tanqer(...), sision(...).
Voir l’exemple
si(x>0 et x<10){ affi(|entre 0 et 10|) }
si(jour==|samedi| ou jour==|dimanche|){ affi(|weekend|) }

Fonctions mathematiques

sin

sin(x)
  • Sinus de x (x en radians).
  • Fonctionne aussi element par element si x est un vecteur ou une matrice.
Voir l’exemple
sin(0)   ->   0
sin(c(0, 1.5708))   ->   [1] 0 1

cos

cos(x)
  • Cosinus de x (x en radians).
  • Fonctionne aussi element par element si x est un vecteur ou une matrice.
Voir l’exemple
cos(0)   ->   1

exp

exp(x)
  • Exponentielle de x (e a la puissance x).
  • Fonctionne aussi element par element si x est un vecteur ou une matrice.
Voir l’exemple
exp(0)   ->   1
exp(1)   ->   2.718...

ln

ln(x)
  • Logarithme neperien (base e) de x. x doit etre strictement positif.
  • Fonctionne aussi element par element si x est un vecteur ou une matrice.
Voir l’exemple
ln(1)   ->   0
ln(exp(1))   ->   1

pusan

pusan(a,b)
  • Calcule a a la puissance b (equivalent a a^b, en version fonction).
  • b peut etre negatif, rationnel/decimal, etc. Utile quand a ou b sont eux-memes des expressions ou resultats de fonctions.
  • Fonctionne aussi element par element si a ou b est un vecteur ou une matrice (memes regles que l'operateur ^).
Voir l’exemple
pusan(2,3)     ->   8
pusan(2,-1)    ->   0.5
pusan(9,0.5)   ->   3

racine

racine(x) ou racineN(x)
  • racine(x) calcule la racine carree de x (equivalent a racine2(x)).
  • racineN(x), avec N un nombre (racine3, racine4, racine10, ...), calcule la racine N-ieme de x.
  • Fonctionne aussi element par element sur un vecteur ou une matrice.
  • Une racine d'indice impair est definie pour un nombre negatif (ex: racine3(-8) = -2) ; une racine d'indice pair non.
Voir l’exemple
racine(9)     ->   3
racine3(8)    ->   2
racine3(-8)   ->   -2

Constantes

VRAI · FAUX

VRAI / FAUX
  • Les deux seules valeurs booleennes (vrai / faux) du langage.
  • Utiles dans les conditions (si, tanqer) et pour le parametre parlig de matrice().
Voir l’exemple
si(3>2){ affi(VRAI) }

pasdefini

pasdefini
  • La valeur |pas definie| du langage (comme VRAI/FAUX, mais pour l'absence de valeur).
  • C'est ce que renvoie un retour sans valeur (ou l'absence de retour) dans une fonction perso.
  • Utilisable dans une comparaison : si(x == pasdefini){ ... }.
Voir l’exemple
fonc f(){ retour }
f()   ->   pasdefini

DIVISION_ZERO · FICHIER_INTROUVABLE · ...

DIVISION_ZERO / FICHIER_INTROUVABLE / FICHIER_DEJA_EXISTANT / FICHIER_INVALIDE / CLE_INTROUVABLE / VARIABLE_INCONNUE / FONCTION_INCONNUE / ATTRIBUT_INCONNU / INDEX_HORS_LIMITE / TYPE_INVALIDE / RECURSION_MAX / PERMISSION_REFUSEE / INDISPONIBLE_HORS_APP / SYNTAXE
  • Les 13 codes d'erreur du langage (voir la section 14, Gestion des erreurs), plus SYNTAXE, sont des constantes (comme VRAI/FAUX) : elles s'ecrivent sans les deux barres verticales (|...|).
  • Chaque constante vaut son propre nom en texte -- comparer code==DIVISION_ZERO revient a comparer deux textes identiques.
  • Utilisees avec attrape(msg, code){...} pour reagir differemment selon la cause d'une erreur interceptee par essai/attrape.
  • Combinables avec l'operateur ou : si(code==FICHIER_INTROUVABLE ou code==CLE_INTROUVABLE){ ... }.
Voir l’exemple
essai { x ~ 10 / 0 }\nattrape(msg, code) {\n    si(code == DIVISION_ZERO){ affi(|Division par zero evitee|) }\n}

saulig

affi(..., saulig, ...) / ecrire(cle, ..., saulig, ...) / c(..., saulig, ...)
  • Saut de ligne : un texte contenant un seul caractere retour a la ligne.
  • Dans affi()/entr(), insere un retour a la ligne a cet endroit dans le message affiche/demande.
  • Utilisable aussi comme valeur ordinaire partout ou une valeur brute est attendue : ecrire(...), ecrire.fichier(...), ajout(...), ajout.fichier(...), c(...), liste(...), matrice(...).
  • Doit toujours apparaitre SEUL comme argument (jamais colle a l'interieur d'un |texte|, sinon ce n'est plus reconnu -- ce serait alors juste le mot 'saulig' litteral).
  • Pour une ligne vide toute seule dans affi(), on peut aussi ecrire affi(||) ou affi( | |).
Voir l’exemple
affi(|Programme de calcul|, saulig, |----------|)
ecrire(|notes|, |Titre|, saulig, |Sous-titre|)   ** liste() : |Titre|, |\n|, |Sous-titre| **

Texte

texte

texte(a, b, ...)
  • Concatene plusieurs parties en UN SEUL texte, exactement comme les arguments de affi()/entr()/~ (avec |texte| et saulig pour un saut de ligne).
  • Contrairement a affi(), ne s'affiche pas : renvoie le texte concatene comme une valeur, utilisable dans une expression.
  • Utile pour construire un texte a passer en UN SEUL argument a ecrire(...), ecrire.fichier(...) ou ajout(...) -- qui, eux, rangent chaque argument separe par une virgule comme un element distinct d'une liste() plutot que de les coller ensemble.
Voir l’exemple
ligne ~ texte(|+ Depot: |, montant, | F|, saulig)
ecrire.fichier(|/sdcard/historique.mld|, h + ligne)

miniscul · majuscul · suprespac

var.miniscul() / var.majuscul() / var.suprespac()
  • miniscul() convertit le texte contenu dans var en minuscules.
  • majuscul() convertit le texte contenu dans var en majuscules.
  • suprespac() supprime les espaces au debut et a la fin du texte.
  • Les parentheses peuvent contenir un espace : var.miniscul( ), var.majuscul( ) ou var.suprespac( ).
  • Les commandes peuvent etre enchainees dans l'ordre : var.miniscul().suprespac() ou var.majuscul().suprespac().
Voir l’exemple
nom~|  BONJOUR  |
nom.miniscul().suprespac()
affi(nom)   ->   bonjour

Console

effa

effa() ou effa(nom1, nom2, ...)
  • effa() : sert a effacer les choses ecrites dans la console.
  • effa(nom1, nom2, ...) : sert a effacer seulement en memoire nom1, nom2, ... s'ils existent en memoire.
Voir l’exemple
effa()        ->   efface toute la console
effa(a, e)    ->   supprime les variables a et e

voi

voi() ou voi(nom1, nom2, ...)
  • voi() : sert a voir les noms de tout ce qui est actuellement stocker en memoire.
  • voi(nom1, nom2, ...) : sert a voir si nom1, nom2, ... sont stocker en memoire.
Voir l’exemple
voi()         ->   liste tous les elements stocker
voi(a, e)     ->   Oui, a et e sont stocker.

Graphique

trac

trac(x, y, ...) ou trac(y, ...)
  • Trace une courbe dans la console, sous forme d'image (canvas) — comme plot(x,y) en Scilab.
  • Les points doivent d'abord etre calcules (avec une boucle pou, ou une expression vectorielle comme y~x*x), puis on appelle trac.
  • trac(x, y) : trace le vecteur y en fonction du vecteur x (memes longueurs).
  • trac(y) : trace le vecteur y en fonction de sa position (1, 2, 3...).
  • Par defaut, la grille n'est pas affichee (comme en Scilab) : utilise grille() pour l'activer.
  • Options facultatives (a la suite, dans n'importe quel ordre) : couleur~|...|, type~|...|, titre~|...|, xlab~|...|, ylab~|...|.
  • couleur (comme en Scilab, mais en francais) : r=rouge, v=vert, b=bleu (par defaut), n=noir, j=jaune, m=magenta, c=cyan, bl=blanc. On peut aussi mettre un code hexadecimal, ex: couleur~|#ff00aa|.
  • type : |-| pour un trait continu (par defaut), |o| pour des points.
Voir l’exemple
x ~ seq(-5,5,0.1)
y ~ x*x
trac(x, y, couleur~|r|, type~|-|, titre~|Ma courbe|)

grille

grille() ou grille(FAUX)
  • Active ou desactive la grille sur le dernier graphique trace avec trac(...) — comme xgrid() en Scilab.
  • grille() : active la grille (par defaut, elle n'est pas affichee).
  • grille(FAUX) : desactive la grille.
  • Doit etre appelee apres trac(...).
Voir l’exemple
x ~ seq(-5,5,0.1)
y ~ x*x
trac(x, y)
grille()
19. Règle de maintenance

Toute nouvelle fonctionnalité doit être ajoutée à l’interpréteur et à cette spécification. La convention de documentation reste : aide() décrit le nom de la commande, tandis que var.commande() décrit son utilisation sur une variable.
