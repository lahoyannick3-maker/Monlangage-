Spécification officielle de MonLangage

Cette page décrit les fonctionnalités réellement présentes dans l’interpréteur de cette version de MonLangage.
aide(spec)
1. Statut et architecture

MonLangage (MLG) est le langage interprété par le moteur présent dans www/index.html de cette application.

Cette spécification décrit l’état fonctionnel de l’interpréteur fourni avec le projet. Elle ne promet pas de fonctionnalités qui ne sont pas présentes dans l’implémentation.

.mlg est l’extension des fichiers de code source MonLangage. .mld est l’extension utilisée pour les sauvegardes de données produites par les fonctions de fichiers.

Le projet Android est construit avec Capacitor. Le dossier www/ est la source web embarquée dans l’APK ; SPECIFICATION.html est donc livré hors ligne avec l’application.

Architecture Android d’exécution : l’application démarre automatiquement un service foreground MonLangageService (ce démarrage automatique est voulu et conservé). Deux boutons lancent un script, avec deux modes distincts :

  • RUN exécute le script dans la console visible de l’application, jamais dans le service. entr() y fonctionne.
  • FOND est un choix explicite de l’utilisateur : le script est remis au service, qui possède sa propre WebView headless, indépendante de celle de l’éditeur, et reste actif même lorsque l’interface n’est plus affichée. Il n’y a pas de console interactive : entr() est indisponible (erreur claire) et la sortie s’affiche à la fin du script. RUN n’envoie jamais un script au service de lui-même.

Le bouton d’arrêt d’urgence n’affiche qu’une seule invite ; l’arrêt d’un script coupe aussi un attendre() en cours. Les erreurs d’un script exécuté dans le service sont affichées en rouge, comme celles de la console. Au retour à l’éditeur, le dialogue de confirmation ne propose pas l’arrière-plan pour un script qui y est déjà.

Clés persistantes : ecrire.cle(cle, valeur), lire.cle(cle), ajout.cle(...), voir.cle() et supri.cle(cle) utilisent le mécanisme de stockage disponible dans le contexte d’exécution. Pour que les clés soient réellement communes entre l’éditeur et le service FOND, les deux contextes doivent être reliés au même stockage natif partagé ; le localStorage propre à une WebView ne doit pas être présenté comme un stockage partagé garanti.

Console et gestionnaire de paquets : l’écran de la console possède un bouton bascule 📦 Paquets / 📦 Console MLG. La console MLG (invite # bleue) exécute du MonLangage ; le gestionnaire de paquets (invite 📦 ambre) est un espace séparé qui n’est pas du MonLangage (voir la section 20).

Pont natif commun : les capacités Android utilisées par MLG sont implémentées une seule fois dans MonLangageBridge. MainActivity utilise ce même pont pour l’interface principale et MonLangageService l’utilise avec une WebView sans interface. Lorsqu’un script lancé par FOND appelle une commande qui nécessite une interface (par exemple ouvrir.whatsapp(), messenger.ouvrir() ou partager.fichier()), le service remet l’action à MainActivity si l’éditeur est actuellement visible ; l’action peut alors s’ouvrir directement. Si l’éditeur n’est pas disponible ou si Android refuse le lancement direct, une notification sert de repli pour déclencher l’action, sans bloquer l’exécution MLG.

Exclusivité d’exécution : un seul script MLG peut être actif à la fois. Une nouvelle demande RUN ou FOND pendant une exécution existante est refusée (Script en cours) ; si un script tourne déjà dans le service, le message indique de l’arrêter avant de relancer RUN.

Performance : le moteur mémorise l’arbre syntaxique (AST) des expressions « pures » et retombe sur l’analyseur d’origine pour les autres ; il mémorise aussi la classification des lignes et le découpage des expressions (caches bornés). Ces optimisations ne changent aucun résultat. Le moteur est préchauffé au démarrage pour l’évaluation d’expressions uniquement. L’exécution dans le service (FOND) démarre à froid, dans une WebView séparée : elle est plus lente au lancement.

aide() est la documentation interactive. aide(nomOuSymbole) donne l’aide d’un élément. aide(spec) ouvre le présent manuel officiel dans un écran dédié.

2. Syntaxe générale

Les instructions structurées utilisent des parenthèses (...) pour leurs paramètres et des accolades { ... } pour leurs blocs.

Les textes littéraux sont écrits entre barres verticales |...|.

Les commentaires commencent par ** et vont jusqu’à la fin de la ligne, sauf à l’intérieur d’un texte littéral |...|.

Les indices commencent à 1, et non à 0.

Le point-virgule ; sépare plusieurs instructions sur une même ligne (a~1;b~2;affi(a+b)). Un simple espace ne sépare pas deux instructions.

Les paramètres nommés utilisent la forme nom~valeur. Cette même notation est utilisée pour l’affectation nom ~ valeur.

Les paramètres de fonction peuvent avoir une valeur par défaut (param~expression) et des paramètres nommés uniquement (*param ou *param~defaut). Les paramètres positionnels sans valeur par défaut doivent précéder ceux qui en ont une.

3. Valeurs et types

Les valeurs documentées par l’interpréteur comprennent : nombre normal, grand entier, texte, booléen, vecteur, matrice, liste, dictionnai, fonction et instance de classe.

Les constantes booléennes sont VRAI et FAUX. Les raccourcis V et F sont reconnus comme leurs équivalents.

pasdefini représente l’absence de valeur.

lettr et Lettr sont des vecteurs constants contenant respectivement les 26 lettres minuscules et majuscules.

Un grand entier est produit par entier(...) et est représenté séparément d’un nombre normal. est.enti(...) et est.reel(...) permettent de les distinguer.

Un dictionnai range des valeurs sous des clés (texte ou nombres) : dictionnai(|nom|: |Yannick|, |age|: 30). Il se lit avec d[cle], s’écrit avec d[cle]~valeur (la clé est créée si besoin), et cle dan d teste l’existence d’une clé. Une copie indépendante d’une liste, d’un dictionnai ou d’une instance s’obtient avec copier(x) (surface) ou copier.profond(x) (complète).

4. Variables et portée

L’affectation utilise nom ~ valeur.

Les variables sont organisées en portées. Les fonctions normales utilisent une portée globale et une portée locale ; les fonctions anonymes capturent leur environnement de création (closure).

Les fonctions appelées ne voient pas automatiquement les variables locales de leurs appelantes : la résolution est lexicale, avec l’environnement capturé pour les fonctions anonymes.

Une variable contenant une fonction peut être appelée comme une fonction (f(5)). Une variable portant le même nom qu’une fonction ou classe peut masquer cette fonction/classe lors d’un appel direct.

5. Expressions et opérateurs

Le moteur possède un tokenizeur et un analyseur d’expressions dédiés ; le code utilisateur n’est pas exécuté avec eval JavaScript.

L’ordre de traitement implémenté est : ou, et, non, dan, comparaisons, +/-, opérateurs multiplicatifs, :, unaire -, puissance ^, puis appels/indices/accès aux attributs.

Les opérations vectorielles et matricielles utilisent un recyclage lorsque l’opération le prévoit. Les dimensions doivent respecter les règles propres à chaque opération.

et et ou court-circuitent, comme en Python : le côté droit n’est pas évalué si le côté gauche suffit à décider, donc x!=0 et 10/x>2 ne divise jamais par zéro quand x vaut 0. Le résultat reste toujours un vrai booléen (VRAI/FAUX), jamais l’opérande brut. non est plus fort que et/ou et s’applique à toute la comparaison qui le suit : non x>5 équivaut à non(x>5).

Sur une matrice carrée, ^ avec un exposant entier positif ou nul est la vraie puissance matricielle (m^3 = m..m..m, m^0 = identité), pas une puissance élément par élément. Un exposant négatif ou non entier, ou une matrice non carrée, donne une erreur claire (utiliser inverse(m) pour l’inverse). Les produits matriciels (.. et ^) arrondissent le bruit de calcul flottant à 1e-6, pour que a..inverse(a) affiche bien la matrice identité.

6. Contrôle du flux

si, sinon si et sinon forment les structures conditionnelles par blocs.

sision(...) est la forme fonctionnelle/vectorisée du choix conditionnel.

pou(...) possède une forme numérique et une forme pou(var dan objet) pour parcourir un vecteur ou une liste() (dans ce dernier cas, var reçoit chaque élément de la liste, pas ses indices).

tanqer(condition){...} répète tant que la condition est vraie. tanqer VRAI{...} et tanqer V{...} fournissent le raccourci de boucle infinie.

casse quitte la boucle courante (comme break en Python ; ce nom remplace l’ancien stop, qui donne maintenant une erreur indiquant le nouveau nom) et continu passe à l’itération suivante. casse ne sort que de la boucle la plus interne ; quitte termine tout le script d’un coup, de n’importe quelle profondeur (comme sys.exit() en Python) : boucles imbriquées, fonctions, modules importés. quitte est une fin normale (aucune erreur, === FIN === affiché) et n’est pas interceptée par essai/attrape ; quitte() est aussi accepté. L’arrêt d’urgence et quitte ne sont jamais traités comme des erreurs du langage.

Le pas de pou ne peut pas être 0 afin d’éviter une boucle infinie.

La profondeur des appels de fonctions est protégée par limiteRecursion() ; la valeur par défaut actuelle est 500 appels imbriqués.

7. Fonctions

Une fonction nommée se déclare avec fonc nom(parametres){...}.

retour valeur termine la fonction et renvoie une valeur. retour ou retour() sans valeur renvoie pasdefini.

Les arguments peuvent être positionnels ou nommés (param~valeur). Les paramètres peuvent avoir une valeur par défaut.

Une fonction peut être passée comme valeur, reçue comme paramètre, renvoyée par retour ou appelée via une variable.

Une fonction anonyme peut être créée avec la forme fonc(parametres) expression. Elle capture l’environnement actif lors de sa création.

8. Classes et objets

Une classe se déclare avec classe NomClasse { ... }, éventuellement herite Parent.

init(moi, ...) est le constructeur lorsqu’il existe. moi désigne l’instance courante et doit être le premier paramètre des méthodes.

Les attributs d’instance se lisent et s’écrivent avec objet.attribut et objet.attribut ~ valeur.

Les attributs déclarés directement dans le corps de la classe, hors méthode, sont des attributs partagés : une seule valeur par classe, accessibles par NomClasse.attribut.

L’héritage recherche les méthodes et attributs partagés dans la chaîne des classes parentes. Une méthode redéfinie dans l’enfant est prioritaire.

parent.methode(moi, ...) appelle la version définie par la classe parente.

est.instance(objet, NomClasse) reconnaît aussi une instance d’une sous-classe de NomClasse.

9. Collections, vecteurs et matrices

c(...) construit un vecteur en aplatissant les vecteurs/matrices fournis et en unifiant leur type.

liste(...) conserve des éléments hétérogènes sans les aplatir.

seq, rep, alea, ralea et debut:fin permettent de construire ou générer des suites/vecteurs.

matrice(...) construit une matrice avec nlig, ncol et parlig ; le remplissage par défaut est colonne par colonne.

trans(m) transpose une matrice.

Les indices de vecteurs/matrices utilisent une base 1. Les sélections multiples, indices logiques et modifications par indexation sont pris en charge.

Écriture avec indexation. v[i] ~ x écrit dans un vecteur, une liste ou (avec m[l,c] ~ x) une matrice ; un indice au-delà de la taille agrandit le vecteur (cases à 0) ou la liste (cases pasdefini). Les crochets peuvent être enchaînés pour modifier l’intérieur d’une liste : l[i][j] ~ valeur (liste de listes), l[2][1] ~ 99 (liste de vecteurs), l[1][2,3] ~ x (liste de matrices), moi.grille[i][j] ~ v (attribut d’instance). Chaque indice avant le dernier doit désigner un seul élément existant d’une liste (erreur claire sinon : indice hors limites, élément pasdefini, ou conteneur qui n’est pas une liste). Un texte placé dans une liste peut être modifié caractère par caractère de la même façon (l[2][1] ~ |Q|). Les espaces autour des crochets sont tolérés (l [2] ~ 9). Un vecteur ou une liste passé en argument à une fonction n’est pas copié : l’écrire dans la fonction modifie l’original.

10. Texte

Un texte littéral utilise |...|.

texte(...) construit une seule valeur texte à partir de plusieurs éléments sans l’afficher.

var.miniscul(), var.majuscul() et var.suprespac() sont des méthodes texte chaînables.

saulig représente un saut de ligne et peut être utilisé comme argument autonome dans plusieurs fonctions de construction/affichage.

Échappements. Dans un texte, l’antislash \ introduit une séquence : \| une barre |, \\ un antislash, \n un saut de ligne, \t une tabulation, \r un retour chariot, \s une espace insécable, \uXXXX et \u{...} un caractère Unicode (\u00e9 donne é, \u{1F600} donne un émoji). Un antislash suivi d’un autre caractère (par exemple \b) reste tel quel, sans avertissement. Le texte se ferme à la première barre non échappée : un texte ne peut donc pas se terminer par un seul antislash, il faut écrire \\.

Texte brut. r|...| n’interprète rien : r|C:\nouveau| contient bien un antislash suivi d’un n. \| ne ferme pas le texte, mais garde ses deux caractères.

Insertion de valeurs. f|...| remplace chaque {expression} par sa valeur, affichée comme dans affi() : f|Total : {prix*qte} euros|. Toute expression est permise sauf un texte |...| (un | non échappé ferme le texte). Une accolade écrite telle quelle s’écrit {{ ou \{ pour {, }} ou \} pour }. Dans les accolades, \| n’est accepté qu’au tout début ou à la toute fin et s’affiche tel quel autour de la valeur : f|{\|e\|}| affiche |5| si e vaut 5. Une accolade vide {}, une accolade jamais fermée ou un \| au milieu sont des erreurs signalées avant l’exécution.

Combinaison. rf|...| et fr|...| combinent texte brut et insertion : rf|C:\{dossier}\a.txt| garde les antislash et remplace {dossier}. Les préfixes r, f, rf et fr doivent être collés à la barre ouvrante ; une variable nommée r ou f reste utilisable.

Un texte s’indexe avec [...], en lecture comme en écriture : t[1] renvoie le premier caractère et t[1]~|B| remplace ce caractère (le texte est reconstruit et réaffecté). lon(t) renvoie la longueur du texte.

11. Entrées et sorties

affi(...) affiche des textes et des expressions.

entr(...) affiche un message puis attend une saisie et renvoie toujours du texte brut, tel qu’il a été tapé (aucune conversion en nombre).

Les variantes entr.secret, entr.nombr, entr.text, entr.oui, entr.Nsecret et entr.Tsecret spécialisent la saisie.

effa() efface la console ; effa(nom...) supprime des variables de la mémoire. voi() inspecte les éléments en mémoire.

Touches (jeux). touche() lit une touche du clavier sans attendre (contrairement à entr()) et touche.dispo() indique si une touche attend d’être lue : ils servent à écrire des jeux jouables à la main (Snake…). Ce sont des commandes MLG autonomes, comme entr() : elles n’affichent aucun bouton ni champ. Le langage ne traduit aucune touche : touche() renvoie la valeur que le clavier annonce, telle quelle (a, Z avec Maj, ArrowUp, Enter, Escape, un espace pour la barre d’espace…). Le premier appel ouvre le clavier du téléphone (comme entr(), grâce à un champ invisible de 1 pixel : aucun champ ni bouton n’apparaît) et active la lecture du clavier physique, sans jamais bloquer le script. Si le clavier a été fermé, toucher la console le rouvre ; il se ferme à la fin du script. Tant qu’un script n’appelle ni touche() ni touche.dispo(), la saisie de la console reste normale. Les touches sont mises en file (les 64 dernières sont gardées) et lues dans l’ordre ; pendant le script, elles ne sont pas tapées dans la console (sauf une saisie entr() en cours). Indisponible en arrière-plan (FOND).

Touches visibles. Un script qui veut des touches à l’écran les construit lui-même avec bouton(libelle, valeur, colonne, ligne) : le bouton, placé dans une grille sous la console, ajoute à la file de touche() la valeur que le script a choisie, comme si on tapait cette touche. Aucun bouton n’existe sans appel à bouton(...) ; ils ne sont pas effacés par effa() et disparaissent à la fin du script ou avec bouton.efface().

12. Sauvegarde et fichiers MLD

ecrire.cle et lire.cle sauvegardent/récupèrent des valeurs dans le stockage interne de l’application.

ecrire.fichier, lire.fichier, existe.fichier, ajout.fichier, ajout.Tfichier, voir.fichier, supri.fichier, dossier.liste, taille.fichier et partager.fichier travaillent avec de vrais fichiers lorsque l’application native est installée.

dossier.liste(dossier) liste TOUS les fichiers d'un dossier (contrairement à voir.fichier, limité aux .mld), utile pour détecter l'apparition d'un nouveau fichier en comparant deux appels successifs. taille.fichier(chemin) renvoie la taille en octets. partager.fichier(chemin) ouvre le sélecteur de partage standard Android pour ce fichier (indépendant de toute messagerie), via un FileProvider dédié.

Les sauvegardes de données sont sérialisées en JSON dans les fichiers .mld.

Les opérations de chemin direct et certaines opérations natives nécessitent l’application Android installée et le pont natif fourni par le projet.

13. Graphiques

trac(...) trace une courbe dans la console sous forme de canvas.

grille() active la grille du dernier graphique et grille(FAUX) la désactive.

Les options de trac comprennent notamment couleur, type, titre, xlab et ylab.

14. Gestion des erreurs

essai{...} attrape{...} intercepte les erreurs du bloc essai.

attrape(msg){...} place le message d’erreur dans la variable msg. attrape(msg, code){...} place en plus un code d’erreur (texte court, ex. |DIVISION_ZERO|) dans la variable code, pour distinguer la cause sans avoir à comparer le texte du message.

Codes d’erreur reconnus : DIVISION_ZERO, FICHIER_INTROUVABLE, FICHIER_DEJA_EXISTANT, FICHIER_INVALIDE, CLE_INTROUVABLE, VARIABLE_INCONNUE, FONCTION_INCONNUE, ATTRIBUT_INCONNU, INDEX_HORS_LIMITE, TYPE_INVALIDE, RECURSION_MAX, PERMISSION_REFUSEE, INDISPONIBLE_HORS_APP. Toute autre erreur (syntaxe, mauvais nombre/type d’argument, structure mal formée...) reçoit le code générique SYNTAXE.

retour, casse et continu sont des signaux de contrôle et ne sont pas transformés en erreurs ordinaires par essai/attrape.

Les messages d’erreur du langage sont toujours en français et compréhensibles : le moteur n’affiche jamais une erreur JavaScript brute ni de jargon interne (par exemple « jeton »). Une erreur de syntaxe affiche son numéro de ligne dans une couleur différente du rouge du message. Une erreur survenue dans un module importé indique le module (et, pour un paquet, paquet:nom/module) et la ligne.

quitte (fin volontaire du script) et l’arrêt d’urgence ne sont pas des erreurs : essai{...} attrape{...} ne les intercepte jamais.

15. Base et résolution des noms

base.nom(...) force l’appel de la fonction intégrée nom, même lorsqu’une fonction utilisateur porte le même nom.

Une fonction utilisateur, une classe ou une variable-fonction peut masquer une fonction intégrée lors d’un appel direct, conformément aux règles de résolution de l’interpréteur.

Les constantes VRAI, FAUX, V, F, pasdefini, lettr et Lettr ne sont pas des fonctions et s’écrivent sans parenthèses.

18. Modules et import

Un script .mlg peut importer un autre fichier .mlg comme module, pour répartir un projet sur plusieurs fichiers réutilisables.

import(nom) charge nom.mlg depuis le dossier du script courant (identifiant nu, sans extension) et rend ses fonctions/classes/variables accessibles avec un préfixe : nom.fonction(...), nom.NomClasse(...), nom.variable.

import(nom, sunom~alias) charge le module sous un préfixe différent (alias.fonction(...)) plutôt que son nom d’origine.

de nom import(a, b) importe seulement les éléments listés, directement utilisables sans préfixe. de nom import(a sunom~alias) renomme un élément importé individuellement (nécessaire en cas de collision avec un nom déjà utilisé dans le script — sinon une erreur claire l’indique).

Un chemin explicite import(|dossier/nom.mlg|) (avec l’extension, entre |...|) permet d’importer un fichier situé ailleurs que le dossier du script courant : absolu s’il commence par /, sinon relatif au dossier du script courant.

Les variables de haut niveau d’un module (ex. une constante) sont accessibles en lecture via le préfixe (nom.variable), mais en lecture seule depuis l’extérieur.

Les classes d’un module conservent leur héritage entre elles. Un module peut importer lui-même un autre module : les chemins relatifs sont alors résolus à partir du dossier du module importeur (pour un module de paquet, le module est cherché d’abord dans son propre paquet). Les imports circulaires sont toujours détectés et refusés. Pour un identifiant nu, la recherche se fait dans l’ordre : dossier local, paquet natif, paquet externe installé (voir la section 20). Dans import(|chemin|), l’extension .mlg est ajoutée automatiquement si elle est absente.

Les instructions import(...)/de ... import(...) sont résolues avant l’exécution du script (comme fonc/classe), quel que soit leur emplacement dans le fichier. Nécessite l’application native installée (chargement de fichier), comme les autres opérations de fichiers.

19. Temps, date et planification

temps() fournit un compteur en millisecondes destiné au chronométrage par différence entre deux appels.

date(), datejour() et heure() fournissent respectivement la date et l'heure actuelles, la date seule et l'heure seule sous forme de texte lisible.

Les fonctions date.annee(), date.mois(), date.jour(), date.jourSemaine(), date.heure(), date.minute() et date.seconde() fournissent les composants numériques de la date/heure actuelle. Le jour de semaine suit la convention 1=lundi jusqu'à 7=dimanche.

attendre(secondes) suspend l'exécution sans bloquer l'application et accepte les fractions de seconde. L'attente est interrompue si l'exécution du script est arrêtée depuis l'interface de l'application.

secondesJusquaProchain(jourSemaine, heure, minute) calcule le délai jusqu'à la prochaine occurrence d'un créneau hebdomadaire. planifier(...) programme au contraire une notification système Android sans bloquer le script, et annuler.planifier(...) annule ce créneau (renvoie VRAI/FAUX selon qu'un créneau existait vraiment).

planifier.liste() renvoie toutes les alarmes actuellement programmées. annuler.planifier.parMessage(texte) et annuler.tout.planifier() annulent respectivement toutes les alarmes portant un message donné, ou absolument toutes les alarmes -- les deux renvoient le nombre d'alarmes annulées.

planifier() nécessite l'application native et les permissions Android correspondantes. Ces fonctions complètent le contrôle temporel de MLG sans être des boucles actives.

Automatisation par vérification d'état : le langage ne fournit pas de surveillance en arrière-plan, mais des fonctions d'état à interroger dans une boucle (tanqer/attendre) du script en cours d'exécution. connexion.disponible()/type.connexion() renseignent sur la connexion internet. niveau.batterie()/batterie.encharge() renseignent sur l'état de charge. sms.recus(depuisSecondes) liste les SMS reçus récemment et envoyer.sms(numero, message) en envoie un. ouvrir.whatsapp(numero, message) et messenger.ouvrir(destinataire, message) ouvrent WhatsApp/Messenger avec un message prérempli -- Android n'autorisant pas une app tierce à appuyer sur Envoyer à la place de l'utilisateur dans une autre app, ce sont des raccourcis, pas des envois automatiques complets (contrairement à envoyer.sms). Toutes ces fonctions nécessitent l'application native ; sms.recus/envoyer.sms demandent en plus une permission Android dédiée.

20. Paquets et gestionnaire de paquets

Un paquet est un ensemble de modules .mlg distribué ensemble ; un module est un seul fichier .mlg. Le nom d’un paquet et celui de ses modules sont deux choses différentes : le paquet outils peut exposer les modules bonjour, trier_vecteur et copier. Comme avec pip et import en Python, install.paquet(nom) installe tout le paquet, tandis que import(module) ne charge que le module demandé.

Deux types de paquets : les paquets natifs sont intégrés à l’application (hors ligne, non désinstallables ; le registre est vide pour l’instant) ; les paquets externes sont téléchargés depuis le dépôt GitHub Paquets_Monlangage- (adresse brute https://raw.githubusercontent.com/lahoyannick3-maker/Paquets_Monlangage-/main/, et non l’URL .git).

Structure du dépôt : index.json à la racine (liste des paquets : nom, version, chemin), puis pour chaque paquet paquets/<nom>/paquet.json (nom, version, description, type, modules) et paquets/<nom>/modules/<module>.mlg. Le champ type vaut "mlg" : un paquet d’un autre type est refusé à l’installation et jamais chargé par import (le type est revérifié à la lecture).

Stockage et sécurité : les paquets externes sont enregistrés dans le stockage interne privé de l’application, jamais dans le stockage visible : l’utilisateur ne les voit ni ne les modifie avec un gestionnaire de fichiers. Les chemins sortant du dossier des paquets (../, chemin absolu) sont refusés. Le téléchargement n’accepte que HTTPS (permission Internet). Un script .mlg ne peut ni lire directement un paquet, ni l’installer ou le désinstaller : les commandes ci-dessous ne sont pas des fonctions MonLangage.

Gestionnaire : il s’ouvre avec le bouton 📦 Paquets de la console. Sa saisie est une mini-syntaxe dédiée (invite 📦 ambre), distincte de la console MLG (invite # bleue). Toutes ses commandes nécessitent l’application native.

Résolution de import(module) : dossier local du script, puis paquet natif, puis paquet externe installé (le paquet dont le champ modules contient ce nom). Un module de paquet qui en importe un autre le cherche d’abord dans son propre paquet, puis dans les autres paquets installés.

install.paquet

install.paquet(nom)
  • Telecharge le paquet depuis le depot (index.json, paquet.json, puis chacun de ses modules) et l'enregistre dans le stockage prive de l'app.
  • Refuse un paquet dont le type n'est pas "mlg", un nom de paquet ou de module invalide, ou un paquet absent du depot.
  • Renvoie un message du type : Paquet "outils" (v1.0.0) installe -- 3 module(s) : bonjour, trier_vecteur, copier.
Voir l’exemple
install.paquet(outils)

desinstall.paquet

desinstall.paquet(nom)
  • Supprime le paquet installe (dossier et modules).
  • Erreur claire si le paquet n'est pas installe.
Voir l’exemple
desinstall.paquet(outils)

liste.paquet

liste.paquet()
  • Liste les paquets installes avec leur version et leur description (ou Aucun paquet installe).
Voir l’exemple
liste.paquet()   ->   outils v1.0.0 -- Premier paquet de test pour MonLangage

info.paquet

info.paquet(nom)
  • Affiche le nom, la version, la description, le type et la liste des modules d'un paquet installe.
  • Erreur claire si le paquet n'est pas installe ; sans nom, rappelle qu'un nom de paquet est attendu.
Voir l’exemple
info.paquet(outils)

paquet.dispo

paquet.dispo()
  • Liste les paquets disponibles sur le depot : telecharge index.json puis le paquet.json de chacun (connexion internet necessaire). N'ecrit rien sur le telephone.
  • Affiche pour chaque paquet son nom, sa version et sa description.
  • Ajoute [installe] si le paquet est deja installe a la meme version, [installe vX, vY disponible] si une version plus recente existe, et [non installable : type "..."] si son type n'est pas "mlg".
  • Ne prend aucun argument.
Voir l’exemple
paquet.dispo()   ->   1 paquet(s) disponible(s) :
outils v1.0.0 -- Premier paquet de test pour MonLangage [installe]

connexion.depot

connexion.depot(jeton) / deconnexion.depot()
  • Enregistre le jeton GitHub qui autorise la publication de paquets sur le depot Paquets_Monlangage-. Le jeton est range dans le stockage prive de l'app : aucun script, aucune commande ne peut le relire.
  • Cree un jeton « fine-grained » limite a ce seul depot, avec la permission Contents : Read and write.
  • Verifie l'acces au depot avant d'enregistrer ; si la verification echoue, aucun jeton n'est garde. Le droit d'ecriture reel n'est teste qu'a la premiere publication.
  • deconnexion.depot() efface le jeton du telephone (le revoquer aussi sur github.com).
  • Disponible uniquement dans l'ecran Paquets, jamais depuis un script .mlg.
Voir l’exemple
connexion.depot(github_pat_xxxxxxxx)\ndeconnexion.depot()

publier.paquet

publier.paquet(dossier) / publier.paquet(|chemin du dossier|)
  • Envoie sur le depot le paquet contenu dans un dossier du telephone : paquet.json et modules/*.mlg.
  • paquet.json doit contenir nom, version, type "mlg" et la liste modules ; chaque module de la liste doit exister dans modules/. Tout est verifie avant le premier envoi.
  • Un paquet deja publie a la meme version est refuse : change la version pour publier une mise a jour. Les modules inchanges ne sont pas renvoyes.
  • index.json est mis a jour en dernier, pour ne jamais lister un paquet incomplet. GitHub peut mettre quelques minutes a servir la nouvelle version a install.paquet.
  • Un module retire de la liste de paquet.json reste sur le depot : utilise retirer.module pour le supprimer vraiment.
  • Pendant la commande, des lignes grises indiquent l'etape en cours (connexion, envoi 2/4...). Le bouton Stop reste utilisable.
  • Necessite connexion.depot(jeton) au prealable. Disponible uniquement dans l'ecran Paquets.
Voir l’exemple
publier.paquet(|/storage/emulated/0/Download/outils|)\n->   Paquet "outils" v1.1.0 publie (3 fichier(s)) :

retirer.module

retirer.module(paquet, module) / retirer.module(paquet, module, confirme)
  • Supprime un module d'un paquet deja publie sur le depot. Sans le mot confirme, la commande montre seulement ce qu'elle ferait et ne modifie rien.
  • Le module est retire de la liste de paquet.json, la version passe de x.y.z a x.y.(z+1) (pour que les mises a jour soient detectees), index.json est aligne, puis le fichier modules/<module>.mlg est supprime.
  • Un fichier orphelin (present sur le depot mais plus liste dans paquet.json) peut aussi etre supprime ainsi.
  • Le dernier module d'un paquet ne peut pas etre retire : utilise retirer.paquet.
  • Si la suppression du fichier echoue apres la mise a jour de paquet.json, un avertissement l'indique (le paquet reste coherent, le fichier est seulement orphelin).
  • Ton dossier local n'est pas modifie : retire aussi le module de paquet.json et de modules/ chez toi, sinon la prochaine publication le remettra. Les telephones qui ont installe le paquet gardent le module jusqu'a leur prochain install.paquet. L'historique GitHub conserve les anciennes versions.
  • Necessite connexion.depot(jeton). Disponible uniquement dans l'ecran Paquets.
Voir l’exemple
retirer.module(outils, copier)\n->   Rien n'a ete modifie. Pour confirmer : retirer.module(outils, copier, confirme)\nretirer.module(outils, copier, confirme)

retirer.paquet

retirer.paquet(nom) / retirer.paquet(nom, confirme)
  • Supprime un paquet entier du depot : son entree dans index.json puis tous ses fichiers (paquet.json et modules/). Sans le mot confirme, la commande liste ce qui serait supprime et ne modifie rien.
  • index.json est mis a jour en premier : le paquet disparait de paquet.dispo() avant que ses fichiers ne soient effaces. Si certains fichiers ne peuvent pas etre supprimes, ils sont listes en erreur.
  • Les telephones qui l'ont installe le gardent jusqu'a desinstall.paquet. L'historique GitHub conserve les fichiers supprimes.
  • Necessite connexion.depot(jeton). Disponible uniquement dans l'ecran Paquets.
Voir l’exemple
retirer.paquet(essai)\nretirer.paquet(essai, confirme)

fonction.dan.module

fonction.dan.module(module) / fonction.dan.module(|chemin|)
  • Affiche les fonctions (avec leurs parametres tels qu'ecrits) et les classes (parent et methodes) d'un module, sans rien executer : un import(...) ou un affi(...) du module ne se declenche jamais.
  • Le module est resolu comme import(...) : local (dossier du script courant, ou chemin |...|), puis paquet natif, puis paquet installe. La premiere ligne indique l'origine trouvee.
  • Un module local n'est visible que si le script courant est enregistre ; un module local du meme nom qu'un paquet a la priorite.
  • Erreur claire si le module est introuvable ou contient une erreur de syntaxe ; un module sans fonc ni classe repond : aucune fonction ni classe.
Voir l’exemple
fonction.dan.module(trier_vecteur)
->   Module "trier_vecteur" (paquet installe "outils")
     Fonctions :
       trier(x, ordre~|croissant|)
21. Référence complète des commandes et symboles

Base

affi

affi(...)
  • Affiche du texte litteral lorsque le texte est entre |...|.
  • Affiche aussi la valeur d'une expression (variable, calcul, vecteur, matrice...).
  • Dans affi(), chaque element a afficher est separe par une virgule (,).
  • Un element couleur(...) place dans affi(...) ne s'affiche pas : il colore le texte qui le suit (voir couleur). Exemple : affi(couleur(|vert|), |OK|, couleur(), |fin|).
Voir l’exemple
affi(|Resultat :|, 2+2)   ->   affiche : Resultat : 4

entr

entr(...)
  • Affiche le message entre |...| puis attend que l'utilisateur tape une reponse.
  • Comme affi(), plusieurs elements separes par une virgule (,) peuvent etre combines dans le message.
  • Renvoie ce que l'utilisateur a tape.
  • Renvoie toujours du texte brut, tel que tape -- jamais converti en nombre (ex: -5, 12, 2.5 ou 2+3 restent tous du texte). Utiliser entr.nombr() si un nombre est necessaire.
  • Le message peut contenir des couleur(...) : entr(couleur(|jaune|), |Ton nom :|, couleur()) (voir couleur).
Voir l’exemple
age ~ entr(|Quel age as-tu, |, prenom, |?|)

entr.secret

entr.secret(|texte|, sty~|*|)
  • Comme entr(), mais la frappe n'est jamais affichee en clair (utile pour un mot de passe ou un code PIN).
  • Sans sty~... : rien n'est affiche du tout pendant la frappe (pas meme un caractere de masquage).
  • Avec sty~... : affiche ce caractere (choisi par le codeur, ex: |*| ou |.|) autant de fois que de caracteres deja tapes.
  • Convertit automatiquement en nombre si possible, sinon renvoie du texte.
Voir l’exemple
pin ~ entr.secret(|Code secret:|, sty~|*|)
secret ~ entr.secret(|Mot de passe:|)   ** rien affiche du tout **

entr.nombr

entr.nombr(...)
  • Comme entr(), mais sans masquer la frappe : redemande automatiquement en boucle tant que la saisie n'est pas un nombre valide.
  • Renvoie toujours un nombre.
Voir l’exemple
montant ~ entr.nombr(|Montant:|)

entr.text

entr.text(...)
  • Comme entr(), mais sans masquer la frappe et sans jamais convertir en nombre : renvoie toujours du texte tel quel.
  • Utile pour un code avec des zeros en tete (ex: |0123|), qui deviendrait sinon le nombre 123 avec entr().
Voir l’exemple
code ~ entr.text(|Code postal:|)

entr.oui

entr.oui(...)
  • Question fermee oui/non : redemande en boucle tant que la reponse n'est pas reconnue.
  • Accepte oui/o/ok/non/n, insensible a la casse et aux espaces.
  • Renvoie directement VRAI ou FAUX, pas besoin de comparer le texte tape.
Voir l’exemple
si(entr.oui(|Confirmer le virement ?|)){ ... }

entr.Nsecret

entr.Nsecret(|texte|, sty~|*|)
  • entr.secret() + validation : redemande en boucle tant que la saisie masquee n'est pas un nombre valide.
  • Renvoie toujours un nombre.
Voir l’exemple
pin ~ entr.Nsecret(|Code (4 chiffres):|, sty~|*|)

entr.Tsecret

entr.Tsecret(|texte|, sty~|*|)
  • entr.secret(), mais renvoie TOUJOURS du texte, jamais converti en nombre.
  • Utile pour un code avec des zeros en tete (ex: |0123|), qui deviendrait sinon le nombre 123.
Voir l’exemple
code ~ entr.Tsecret(|Code:|, sty~|*|)

Sauvegarde

ecrire.cle

ecrire.cle(cle, valeur) ou ecrire.cle(cle, val1, val2, ...)
  • Sauvegarde silencieuse et immediate : reste dans l'app, aucune interaction utilisateur.
  • N'importe quelle valeur peut etre sauvegardee : nombre, texte, booleen, vecteur, matrice, liste, instance de classe.
  • Avec plusieurs valeurs, elles sont regroupees et sauvegardees comme une liste() (types conserves, pas de fusion).
  • cle doit etre du texte. Ecraser une cle deja utilisee remplace l'ancienne sauvegarde.
Voir l’exemple
ecrire.cle(|mon_compte|, moi)
ecrire.cle(|scores|, 12, |bravo|, VRAI)   ** sauvegarde une liste() **

lire.cle

lire.cle(cle)
  • Recupere une valeur sauvegardee avec ecrire.cle(...).
  • Renvoie pasdefini si la cle n'existe pas.
Voir l’exemple
c ~ lire.cle(|mon_compte|)

ecrire.fichier

ecrire.fichier(nom, valeur, ecra~FAUX) ou ecrire.fichier(chemin, val1, val2, ..., ecra~FAUX)
  • ecrire.fichier(nom, valeur) : ouvre le navigateur de fichiers integre pour choisir ou enregistrer un vrai fichier .mld.
  • ecrire.fichier(chemin, valeur) : si nom contient un '/', ecriture DIRECTE a cet emplacement, sans rien afficher a l'ecran.
  • Avec plusieurs valeurs, elles sont regroupees comme une liste() (meme regle que ecrire.cle()).
  • ecra~FAUX par defaut : si le fichier existe deja, l'ecriture est REFUSEE (erreur, a intercepter avec essai/attrape). ecra~VRAI ecrase sans verifier.
  • Le chemin direct et la verification ecra ne fonctionnent que dans l'app installee (pas en previsualisation navigateur).
  • Contrairement a ecrire.cle(), le fichier peut ensuite etre partage, copie, deplace hors de l'app.
  • Un TEXTE est enregistre tel quel, avec ses vraies lignes (un journal reste lisible dans l'IDE) ; une liste ou un dictionnai est ecrit sur plusieurs lignes. lire.fichier(...) renvoie toujours la valeur d'origine.
Voir l’exemple
ecrire.fichier(|sauvegarde_banque|, moi, ecra~VRAI)
si(existe.fichier(|/storage/emulated/0/Download/banque.mld|)) { affi(|deja present|) }
sinon { ecrire.fichier(|/storage/emulated/0/Download/banque.mld|, moi) }

existe.fichier

existe.fichier(chemin)
  • Renvoie VRAI si un fichier existe deja a ce CHEMIN COMPLET (avec '/'), FAUX sinon.
  • A utiliser typiquement avant ecrire.fichier(chemin, valeur) pour decider d'ecraser ou non.
  • Disponible uniquement dans l'app installee (pas en previsualisation navigateur).
Voir l’exemple
si(existe.fichier(|/storage/emulated/0/Download/banque.mld|)) { affi(|Fichier deja present|) }

lire.fichier

lire.fichier() ou lire.fichier(chemin)
  • lire.fichier() : ouvre le navigateur de fichiers du telephone et attend que l'utilisateur choisisse un fichier sauvegarde avec ecrire.fichier(...).
  • lire.fichier(chemin) : lit DIRECTEMENT le fichier a ce chemin, sans rien afficher a l'ecran.
  • Le chemin direct ne fonctionne que dans l'app installee (pas en previsualisation navigateur).
  • Renvoie la valeur sauvegardee dans ce fichier.
Voir l’exemple
c ~ lire.fichier()
c ~ lire.fichier(|/storage/emulated/0/Download/banque.mld|)

ajout.cle

ajout.cle(cle, valeur, ...)
  • Ajoute une ou plusieurs valeurs a une cle DEJA SAUVEGARDEE avec ecrire.cle(...), sans rien ecraser.
  • Erreur si la cle n'existe pas encore : utiliser ecrire.cle(...) pour la creer d'abord.
  • Si la cle contient un vecteur, il est etendu directement (comme .ajout() dessus), sans devenir une liste().
  • Si la cle contient deja une liste(), les nouvelles valeurs s'y ajoutent simplement.
  • Sinon (nombre, texte, booleen, matrice, instance), l'ancienne valeur devient le premier element d'une nouvelle liste().
Voir l’exemple
ecrire.cle(|notes|, c(12,15))
ajout.cle(|notes|, 9, 18)   ** notes reste un vecteur : 12 15 9 18 **
ecrire.cle(|score|, 12)
ajout.cle(|score|, 15, 9)   ** score devient une liste() : 12, 15, 9 **

ajout.fichier

ajout.fichier(nom, valeur, ...) ou ajout.fichier(chemin, valeur, ...)
  • Ajoute une ou plusieurs valeurs a un fichier DEJA SAUVEGARDE avec ecrire.fichier(...), sans l'ecraser.
  • ajout.fichier(nom, ...) : ouvre le navigateur de fichiers integre pour choisir le fichier existant a completer.
  • ajout.fichier(chemin, ...) : si nom contient un '/', le fichier doit deja exister exactement a cet emplacement.
  • Meme logique de fusion que ajout.cle(cle, ...) ci-dessus.
  • Disponible uniquement dans l'app installee (pas de repli en previsualisation navigateur, contrairement a ecrire.fichier()).
Voir l’exemple
ajout.fichier(|/storage/emulated/0/Download/scores.mld|, 15, 9)

ajout.Tfichier

ajout.Tfichier(nom, valeur, ...) ou ajout.Tfichier(chemin, valeur, ...)
  • Variante de ajout.fichier(...) reservee aux fichiers dont le contenu sauvegarde est du TEXTE (cree avec ecrire.fichier(chemin, |...|)).
  • Concatene directement le texte a la suite de l'existant (comme le ferait toi-meme lire.fichier()+concatenation+ecrire.fichier(ecra~VRAI)), sans jamais transformer le contenu en liste().
  • ajout.fichier(...) classique ne sait pas faire ca : sur un texte, il transforme l'existant en 1er element d'une liste() au lieu de le prolonger -- ajout.Tfichier() comble ce cas precis.
  • Erreur si le fichier n'existe pas encore, ou si son contenu sauvegarde n'est pas du texte (utiliser ajout.fichier() dans ce cas).
  • Meme regle nom/chemin que ajout.fichier(...) : sans '/' ouvre le navigateur integre, avec '/' chemin direct.
Voir l’exemple
ecrire.fichier(|/sdcard/historique.mld|, ||)
ajout.Tfichier(|/sdcard/historique.mld|, texte(|# Depot: |, 500, saulig))

voir.cle

voir.cle()
  • Renvoie un vecteur avec les NOMS de toutes les cles actuellement sauvegardees avec ecrire.cle(...) (pas leur contenu).
  • Permet de savoir ce qui existe sans devoir tout effacer via 'Effacer donnees utilisateur' de l'app (qui vide TOUTES les cles a la fois).
  • Vecteur vide si aucune cle n'est sauvegardee.
Voir l’exemple
affi(voir.cle())

supri.cle

supri.cle(cle)
  • Supprime UNE cle precise sauvegardee avec ecrire.cle(...), sans toucher aux autres.
  • Erreur si la cle n'existe pas -- verifiable avant avec voir.cle().
Voir l’exemple
supri.cle(|scores|)

voir.fichier

voir.fichier() ou voir.fichier(dossier)
  • Renvoie un vecteur avec les NOMS des fichiers .mld presents dans un dossier (pas leur contenu).
  • Sans argument, utilise le dossier racine du stockage de l'appareil.
  • L'app ne tient pas de registre central de tous les fichiers crees avec ecrire.fichier() (ils peuvent etre ecrits a n'importe quel chemin) : voir.fichier() liste le contenu d'UN dossier donne, comme le navigateur de fichiers integre.
  • Disponible uniquement dans l'app installee (pas en previsualisation navigateur).
Voir l’exemple
affi(voir.fichier(|/storage/emulated/0/Download|))

supri.fichier

supri.fichier(nom) ou supri.fichier(chemin)
  • Supprime UN fichier precis, sans toucher aux autres.
  • Sans '/' : ouvre le navigateur de fichiers integre en mode 'ouvrir' pour choisir le fichier a supprimer.
  • Avec un chemin complet (avec '/') : suppression DIRECTE a cet emplacement, sans rien afficher a l'ecran -- erreur si le fichier n'existe pas (verifiable avant avec existe.fichier(...)).
  • Disponible uniquement dans l'app installee (pas en previsualisation navigateur).
Voir l’exemple
supri.fichier(|/storage/emulated/0/Download/scores.mld|)

dossier.liste

dossier.liste() ou dossier.liste(dossier)
  • Renvoie un vecteur avec les NOMS de TOUS les fichiers d'un dossier (contrairement a voir.fichier(), pas seulement les .mld).
  • Sans argument, utilise le dossier racine du stockage de l'appareil.
  • Utile pour detecter l'apparition d'un nouveau fichier, en comparant deux appels successifs a intervalle regulier (tanqer/attendre).
  • Necessite l'application native et la permission de stockage (comme voir.fichier()).
Voir l’exemple
avant ~ dossier.liste(|/sdcard/Download|)
tanqer VRAI{
    attendre(10)
    maintenant ~ dossier.liste(|/sdcard/Download|)
    pou(f dan maintenant){
        si(non (f dan avant)){ affi(|Nouveau fichier : |, f) }
    }
    avant ~ maintenant
}

partager.fichier

partager.fichier(chemin)
  • Ouvre le selecteur de partage standard Android (Bluetooth, email, Drive, n'importe quelle app acceptant un fichier) pour ce fichier -- PAS specifique a une messagerie, c'est le meme selecteur "Partager" que dans n'importe quelle app Android.
  • Erreur si le fichier n'existe pas a ce chemin (verifiable avant avec existe.fichier(...)).
  • Necessite l'application native et la permission de stockage.
Voir l’exemple
partager.fichier(|/sdcard/Download/rapport.pdf|)

taille.fichier

taille.fichier(chemin)
  • Renvoie la taille du fichier en OCTETS.
  • Erreur si le fichier n'existe pas a ce chemin (verifiable avant avec existe.fichier(...)).
  • Necessite l'application native et la permission de stockage.
Voir l’exemple
affi(taille.fichier(|/sdcard/Download/rapport.pdf|) / 1000, | Ko|)

Modules

import

import(nom) / import(nom, sunom~alias) / import(|dossier/nom.mlg|)
  • Charge nom.mlg comme module et rend ses fonctions/classes/variables accessibles avec un prefixe : nom.fonction(...), nom.NomClasse(...), nom.variable.
  • Identifiant nu (sans extension) : cherche nom.mlg dans le dossier du script courant.
  • sunom~alias : charge le module sous un prefixe different (alias.fonction(...)) au lieu de son nom d'origine.
  • Chemin explicite entre |...| : absolu s'il commence par /, sinon relatif au dossier du script courant. L'extension .mlg est ajoutee automatiquement si elle est absente (import(|dossier/nom|) equivaut a import(|dossier/nom.mlg|)).
  • Identifiant nu : resolution dans l'ordre local (dossier du script) -> paquet natif -> paquet externe installe (voir la section 20). Un chemin |...| explicite ne cherche jamais dans les paquets.
  • Un script jamais enregistre n'a pas de dossier local : un identifiant nu est alors cherche directement dans les paquets, et un chemin relatif |...| donne une erreur claire (enregistre le script ou utilise un chemin absolu).
  • Les variables de haut niveau du module sont accessibles en lecture via le prefixe, mais en lecture seule.
  • Resolu avant l'execution du script (comme fonc/classe), quel que soit son emplacement dans le fichier.
  • Necessite l'application native installee (chargement de fichier).
  • Un module peut en importer un autre : les chemins relatifs se resolvent depuis le dossier du module importeur, et un module de paquet cherche d'abord dans son propre paquet. Les imports circulaires sont detectes et refuses (erreur claire indiquant la chaine).
Voir l’exemple
import(geometrie)
affi(geometrie.PI)
affi(geometrie.aire_cercle(3))

Controle

pou

pou(var, debut, fin, pas){ ... } / pou(var dan objet){ ... } / pou(a, b dan objet){ ... }
  • Repete le bloc entre accolades. Trois syntaxes possibles.
  • 1) pou(var, debut, fin, pas) : var prend d'abord la valeur debut, puis debut+pas, et ainsi de suite jusqu'a fin (fin incluse). pas est facultatif : vaut 1 par defaut, et peut etre negatif (pour compter a l'envers).
  • debut, fin et pas peuvent etre des expressions complexes (avec des parentheses, ^, des appels de fonction, etc.), separees par des virgules.
  • 2) pou(var dan objet) : var prend tour a tour chaque valeur de objet : chaque element d'un vecteur ou d'une liste(), chaque lettre d'un texte, chaque CLE d'un dictionnai (pas les indices).
  • 3) pou(a, b dan objet) : DEPAQUETE chaque element de objet dans plusieurs variables, comme for a, b in ... en Python. Chaque element doit etre une liste ou un vecteur contenant exactement autant de valeurs que de variables (2, 3 ou plus). Les noms doivent etre differents.
  • Pour avoir la position de chaque element : pou(i, x dan enumerer(objet)). Pour avoir les cles et les valeurs d'un dictionnai : pou(k, v dan paires(d)). Voir aide(enumerer).
  • casse permet d'arreter la boucle avant la fin (voir aide(casse)).
Voir l’exemple
pou(i, 1, 5){ affi(i) }   ->   affiche 1 2 3 4 5
pou(i, 10, 1, -1){ affi(i) }   ->   compte a l'envers de 10 a 1
pou(x dan c(3,7,9)){ affi(x) }   ->   affiche 3 7 9
pou(c dan |abc|){ affi(c) }   ->   affiche a b c
pou(a, b dan liste(liste(1,2), liste(3,4))){ affi(a, b) }   ->   1 2, puis 3 4
pou(i, c dan enumerer(|abc|)){ affi(i, c) }   ->   1 a, 2 b, 3 c
pou(k, v dan paires(d)){ affi(k, v) }   ->   chaque cle d'un dictionnai et sa valeur

enumerer · paires

enumerer(objet) / paires(d)
  • enumerer(objet) renvoie une liste de paires liste(position, element), la position commencant a 1, pour un vecteur, une liste, un texte (chaque lettre) ou un dictionnai (chaque cle). paires(d) renvoie une liste de paires liste(cle, valeur) pour un dictionnai.
  • Ils servent avec pou(...) a deux variables : pou(i, x dan enumerer(l)) et pou(k, v dan paires(d)), comme enumerate(l) et d.items() en Python.
  • Ce sont des listes ordinaires : on peut aussi les trier, les parcourir avec une seule variable ou les ranger dans une variable.
Voir l’exemple
pou(i, x dan enumerer(liste(10,20))){ affi(i, x) }   ->   1 10, puis 2 20
d ~ dictionnai(|nom|: |Awa|, |age|: 31)
pou(k, v dan paires(d)){ affi(k, v) }   ->   nom Awa, puis age 31

casse

casse
  • Arrete immediatement la boucle (pou ou tanqer) en cours, et continue l'execution juste apres cette boucle (comme break en Python).
  • Ne sort que de la boucle la plus interne : pour sortir de plusieurs boucles imbriquees d'un coup, utilise quitte.
  • Utilisable a l'interieur d'un pou(...){...} ou d'un tanqer(...){...}, y compris a l'interieur d'un si(...) place dans la boucle.
  • casse remplace l'ancien nom stop : ecrire stop donne une erreur qui indique le nouveau nom.
Voir l’exemple
pou(i, 1, 10){
  si(i==4){ casse }
  affi(i)
}   ->   affiche 1 2 3

quitte

quitte
  • Termine immediatement TOUT le script, de n'importe quelle profondeur : boucles imbriquees, fonctions, modules importes (comme sys.exit() en Python).
  • Fin normale : aucune erreur n'est affichee, et un bloc essai{...} ne l'intercepte pas.
  • Contrairement a casse (qui ne sort que de la boucle la plus interne), quitte n'execute plus aucune ligne apres lui.
  • Utilisable partout, y compris hors d'une boucle. quitte() est accepte aussi.
Voir l’exemple
pou(i, 1, 3){
  pou(j, 1, 3){
    si(i*j==4){ quitte }
    affi(i, j)
  }
}   ->   s'arrete des que i*j vaut 4

rythme

rythme(secondes){ ... }
  • Repete le bloc a cadence reguliere : un tour toutes les `secondes`. Le temps passe dans le bloc est deduit de l'attente, donc le rythme reste regulier meme si ton code prend du temps, alors que tanqer(VRAI){ ... attendre(0.04) } ralentit des qu'un tour est long. La duree doit etre d'au moins 0.001.
  • Si un tour dure plus que la duree, il n'y a pas de rattrapage en rafale : le tour suivant demarre tout de suite et la cadence repart de la.
  • Boucle infinie : sors avec casse (quitte la boucle) ou quitte (arrete le script). continu saute la fin du tour mais garde la cadence. rythme n'affiche rien tout seul : appelle zone.montre() toi-meme dans le bloc.
Voir l’exemple
zone(100, 160)
y~0
rythme(0.05){
  zone.efface()
  zone.rectangle(45, y, 10, 10, |vert|)
  zone.montre()
  y~y+2
  si(y>150){ casse }
}

continu

continu
  • Interrompt uniquement le tour en cours de la boucle (pou ou tanqer), et passe directement au tour suivant : le reste du bloc est saute pour ce tour, mais la boucle continue.
  • Contrairement a casse, ca ne quitte pas la boucle.
  • Utilisable a l'interieur d'un pou(...){...} ou d'un tanqer(...){...}, y compris a l'interieur d'un si(...) place dans la boucle.
Voir l’exemple
pou(i, 1, 5){
  si(i==3){ continu }
  affi(i)
}   ->   affiche 1 2 4 5

tanqer

tanqer(condition){ ... } / tanqer VRAI{ ... }
  • Repete le bloc tant que la condition reste vraie.
  • S'arrete des que la condition devient fausse (ou plus tot si casse est rencontre).
  • tanqer VRAI{...} (ou tanqer V{...}) : raccourci sans parentheses pour une boucle infinie, comme while True en Python. Pas besoin d'ecrire une condition bidon toujours vraie.
Voir l’exemple
x ~ 0
tanqer(x<5){ x ~ x+1 }

i ~ 0
tanqer VRAI{
  i ~ i+1
  si(i>=3){ casse }
}

si

si(condition){ ... }
  • Execute le bloc uniquement si la condition est vraie. Fonctionne comme if() en R.
  • Peut etre suivi de sinon si(...){...} et/ou d'un sinon final (tous optionnels).
Voir l’exemple
si(note>=10){ affi(|Reussi|) }

sinon

sinon{ ... }
  • Execute son bloc uniquement quand aucune condition precedente (si ou sinon si) n'etait vraie. Fonctionne comme else en R.
  • Un seul bloc au total est execute parmi si/sinon si/sinon : le premier dont la condition est vraie.
  • Toujours place juste apres un si(...){...} ou un sinon si(...){...}, jamais seul.
Voir l’exemple
si(note>=10){ affi(|Reussi|) } sinon{ affi(|Echoue|) }

sinon si

sinon si(condition){ ... }
  • Ajoute une condition supplementaire apres un si(...) (ou un autre sinon si), comme else if en R.
  • On peut en enchainer plusieurs a la suite d'un si(...).
  • Un seul bloc au total est execute parmi si/sinon si/sinon : le premier dont la condition est vraie.
  • Peut etre suivi d'autres sinon si(...){...} et/ou d'un sinon final (tous optionnels).
Voir l’exemple
si(note>=16){ affi(|Excellent|) } sinon si(note>=10){ affi(|Reussi|) } sinon{ affi(|Echoue|) }

sision

sision(condition, valeurSiVrai, valeurSiFaux)
  • Version vectorisee (element par element) de si/sinon, comme ifelse() en R.
  • condition peut etre un vecteur de tests (ex: x>0) : le resultat est un vecteur ou chaque element vient de valeurSiVrai ou valeurSiFaux selon le test correspondant.
  • valeurSiVrai et valeurSiFaux peuvent etre des scalaires ou des vecteurs (recycles si plus courts que condition, comme les autres operations vectorielles).
  • Si condition est un simple scalaire, renvoie directement valeurSiVrai ou valeurSiFaux.
Voir l’exemple
x ~ seq(-2,2,1)
affi(sision(x>=0, x, x*-1))   ->   [1] 2 1 0 1 2

essai · attrape · finalement

essai{ ... } attrape(msg){ ... } / essai{ ... } attrape{ ... } / essai{ ... } finalement{ ... } / essai{ ... } attrape{ ... } finalement{ ... }
  • Intercepte une erreur levee dans le bloc essai au lieu de planter tout le script.
  • Si une erreur survient dans essai, l'execution du bloc s'arrete et le bloc attrape s'execute a la place.
  • Si aucune erreur ne survient, le bloc attrape est entierement ignore.
  • attrape(msg){...} recupere le message d'erreur (texte) dans la variable msg, ou la valeur donnee a lever.erreur (n'importe quel type). attrape{...} (sans parametre) l'ignore.
  • attrape se place juste apres un essai{...}, jamais seul. finalement{...} (facultatif) se place juste apres essai{...} ou apres attrape{...}.
  • finalement{...} s'execute TOUJOURS apres le bloc : que tout se soit bien passe, qu'une erreur ait ete rattrapee ou non, ou que le bloc se termine par retour, casse, continu ou quitte. Il sert a nettoyer (effacer des boutons, arreter un service, ecrire un journal).
  • Si une erreur n'est pas rattrapee, elle repart apres finalement. Une erreur levee dans finalement remplace l'ancienne ; un retour, casse ou continu dans finalement prend le pas sur celui en attente.
  • finalement ne s'execute pas apres un arret manuel du script (bouton Retour) : l'utilisateur veut arreter.
  • Ne peut pas empecher un arret manuel du script (bouton Retour pendant l'execution) : cela remonte toujours en dehors de essai/attrape.
Voir l’exemple
essai {
    ecrire.fichier(|/storage/emulated/0/Download/save.mld|, moi)
} attrape(msg) {
    affi(|Echec de sauvegarde :|, msg)
}

essai {
    ** jeu avec bouton(...) et touche() **
} finalement {
    bouton.efface()      ** s'execute meme apres une erreur ou quitte
}

lever.erreur

lever.erreur valeur
  • Ecritures acceptees (comme retour) : lever.erreur valeur / lever.erreur(valeur) / lever.erreur (seul, voir plus bas).
  • Leve une erreur depuis ton programme (comme raise en Python) : l'execution s'arrete et remonte jusqu'au premier essai{...} attrape(...){...} qui l'entoure.
  • La valeur peut etre de n'importe quel type : texte, nombre, dictionnai, instance de classe... attrape(e) la recoit telle quelle. Les erreurs du langage (division par zero...) restent du texte.
  • Plusieurs elements separes par des virgules sont assembles en un seul texte, comme affi() : lever.erreur |age invalide :|, age.
  • Si personne n'attrape l'erreur, le script s'arrete avec : Erreur ligne N: suivi de la valeur ecrite comme affi() le ferait.
  • Avec attrape(e, code), code vaut ERREUR_UTILISATEUR. Pour reagir selon le TYPE d'erreur, leve une instance de classe et teste-la avec est.instance(e, MaClasse).
  • lever.erreur seul (ou lever.erreur()), dans un bloc attrape, RELANCE l'erreur en cours (ex : noter le probleme puis le laisser remonter). En dehors d'un attrape : erreur claire "rien a relancer".
  • finalement{...} s'execute toujours, meme quand l'erreur n'est pas attrapee.
Voir l’exemple
fonc retirer(solde, montant){
    si(montant > solde){
        lever.erreur |Solde insuffisant|
    }
    retour solde - montant
}
essai {
    retirer(10, 50)
} attrape(msg) {
    affi(|Echec :|, msg)
}

classe ErreurSolde { }
essai {
    lever.erreur ErreurSolde()
} attrape(e) {
    si(est.instance(e, ErreurSolde)){ affi(|solde trop bas|) }
}

global

global nom1, nom2
  • A ecrire au DEBUT d'une fonction : dit que ces noms designent des variables du PROGRAMME (le niveau tout en haut), pas des variables locales.
  • REGLE (comme Python) : dans une fonction, nom ~ valeur cree TOUJOURS une variable locale. Sans global, la variable du programme n'est donc jamais modifiee. Lire une variable du programme marche sans rien ecrire.
  • Avec global score, score ~ score + 1 modifie le score du programme. Si score n'existe pas encore, il est cree au programme a la premiere affectation.
  • Ecrire global apres avoir deja utilise le nom (ou si c'est un parametre) est une erreur claire. Hors d'une fonction, global n'a pas de sens (erreur de syntaxe).
  • Pour modifier une variable de la fonction qui CONTIENT la tienne (fonction imbriquee), utilise englobant.
Voir l’exemple
score ~ 0
fonc gagner(){
    global score
    score ~ score + 1
}
fonc essai(){
    score ~ 100        ** variable LOCALE : le score du programme ne change pas **
}
gagner()
essai()
affi(score)   ->   1

englobant

englobant nom1, nom2
  • A ecrire au DEBUT d'une fonction definie a l'interieur d'une autre : dit que ces noms designent des variables de la fonction englobante (la plus proche qui les possede).
  • Les fonctions nommees imbriquees gardent une reference vers les variables de la fonction qui les a creees (fermeture) : chaque appel de la fonction englobante a ses propres variables.
  • Lire une variable de la fonction englobante marche sans rien ecrire ; pour la MODIFIER, il faut englobant (sinon nom ~ valeur cree une variable locale).
  • Erreur claire si aucune fonction englobante n'a cette variable. Pour une variable du programme, utilise global.
Voir l’exemple
fonc compteur(){
    n ~ 0
    fonc suivant(){
        englobant n
        n ~ n + 1
        retour n
    }
    retour suivant
}
a ~ compteur()
b ~ compteur()
affi(a(), a(), b())   ->   1 2 1

verification de syntaxe

automatique, avant chaque execution
  • Avant d'executer la moindre ligne, MonLangage relit TOUT le script et verifie sa syntaxe, comme Python. Si une erreur est trouvee, rien n'est execute : aucun fichier ecrit, aucun SMS envoye, aucune notification.
  • Chaque erreur est affichee avec son numero de ligne : Erreur de syntaxe ligne N : ...
  • Verifie : accolades { } equilibrees, | de fermeture des textes, en-tetes si(...), sinon si(...), sinon, pou(...), tanqer(...), fonc, classe, essai et attrape bien formes et suivis de {, sinon et attrape places juste apres si et essai, expressions bien formees (parentheses, crochets, operateurs, = au lieu de ==), imports bien formes, lignes qui ne sont aucune commande connue.
  • Verifie aussi que retour n'est utilise que dans une fonction (fonc), et casse / continu que dans une boucle (pou ou tanqer). stop (ancien nom de casse) est signale avec le nouveau nom.
  • Une expression seule sur une ligne (3 * 4, v[2], lettr) n'est acceptee que dans la console : dans un script, ecris affi(3 * 4).
  • Ne verifie PAS (detecte pendant l'execution, comme en Python) : variable ou fonction inconnue, types, nombre d'arguments, fichiers.
Voir l’exemple
envoyer.notif(|Debut|)
x = 5   ->   Erreur de syntaxe ligne 2 : Commande inconnue... et la notification n'est PAS envoyee

instruction sur plusieurs lignes

nom( argument1, argument2 )
  • Tant qu'une parenthese ( ou un crochet [ est ouvert, la fin de ligne ne termine pas l'instruction : elle continue sur la ligne suivante.
  • Fonctionne pour liste(), affi(), entr(), envoyer.notif(), tous les appels de fonction, les conditions si(...), les en-tetes pou(...), les indices v[...], etc.
  • Les commentaires ** sont permis entre les lignes. Un texte |...| peut lui aussi contenir des sauts de ligne.
  • Si une parenthese est oubliee, l'instruction continue jusqu'a la prochaine accolade ou la fin du script : l'erreur de syntaxe indique alors sur quelles lignes elle s'etend.
Voir l’exemple
chaines ~ liste(
    liste(|NCI|, |19:45:00|),
    liste(|La 3|, |19:30:00|)
)
affi(chaines[1][1])   ->   NCI

limiteRecursion

limiteRecursion() / limiteRecursion(n)
  • Lit ou change la limite d'appels de fonction imbriques autorises (protection contre une recursion infinie), comme sys.setrecursionlimit(...) en Python.
  • limiteRecursion() sans argument : lecture seule, renvoie la limite actuelle (500 par defaut).
  • limiteRecursion(n) : change la limite a n et renvoie l'ANCIENNE valeur (pratique pour la restaurer ensuite).
  • Refuse un nombre non entier ou <= 0, ou une valeur inferieure a la profondeur d'appel actuelle.
  • Se reinitialise a 500 a chaque nouvelle execution du script.
Voir l’exemple
ancienne ~ limiteRecursion(2000)
** ... code qui a besoin de plus de profondeur ... **
limiteRecursion(ancienne)

fonc

fonc nom(param1, param2){ ... }
  • Definit une fonction reutilisable, avec un nom et des parametres.
  • Le bloc entre accolades s'execute a chaque appel de la fonction.
  • VARIABLES : dans une fonction, nom ~ valeur cree toujours une variable LOCALE (comme Python). Lire une variable de l'exterieur marche sans rien ecrire ; pour la MODIFIER, utilise global (variable du programme) ou englobant (variable de la fonction qui contient la tienne).
  • Une fonction definie dans une autre garde l'acces aux variables de celle-ci (fermeture), comme une fonction anonyme.
Voir l’exemple
fonc carre(x){ retour x*x }
affi(carre(5))   ->   25

retour

retour valeur
  • Arrete l'execution de la fonction et renvoie la valeur donnee comme resultat de l'appel.
  • La valeur renvoyee peut etre un nombre, mais aussi un vecteur ou une matrice (comme en R).
  • Utilisable uniquement a l'interieur d'une fonction (fonc).
Voir l’exemple
fonc double(x){ retour x*2 }
fonc doubleVecteur(v){ retour(v*2) }
affi(doubleVecteur(c(1,2,3)))   ->   2 4 6

classe

classe NomClasse [herite NomParent] { fonc init(moi, ...){...} fonc methode(moi, ...){...} }
  • Definit une classe (comme class en Python) : un modele pour creer des objets (instances).
  • init(moi, ...) est le constructeur, appele automatiquement a la creation d'une instance.
  • Chaque methode doit prendre moi comme premier parametre (comme self en Python).
  • Instanciation : a ~ NomClasse(arguments). Attribut : moi.nom ~ valeur (ecriture), a.nom (lecture). Methode : a.methode(...).
  • herite NomParent (facultatif) fait heriter de toutes les methodes de NomParent, voir herite.
Voir l’exemple
classe Animal {
    fonc init(moi, nom){ moi.nom ~ nom }
    fonc parler(moi){ affi(moi.nom, |fait un bruit.|) }
}
a ~ Animal(|Rex|)
a.parler()

attribut partage

classe NomClasse { attribut ~ valeur ... } puis NomClasse.attribut
  • Un attribut declare directement dans le corps de la classe (hors de toute methode) est PARTAGE par toutes les instances : une seule valeur pour toute la classe, pas une copie par instance.
  • S'initialise une seule fois, au demarrage du script (pas a chaque instanciation).
  • Se lit et se modifie avec NomClasse.attribut (le nom de la CLASSE, pas moi ni une instance) : NomClasse.attribut ~ nouvelleValeur.
  • Utile pour un compteur global, un reglage ou une valeur par defaut commune a toutes les instances.
Voir l’exemple
classe Voiture {
    compteurVentes ~ 0
    fonc init(moi, modele){
        moi.modele ~ modele
        Voiture.compteurVentes ~ Voiture.compteurVentes + 1
    }
}
v1 ~ Voiture(|Clio|)
v2 ~ Voiture(|208|)
affi(Voiture.compteurVentes)   ->   2

herite

classe Enfant herite Parent { ... }
  • Fait heriter une classe d'une autre (comme class Enfant(Parent): en Python).
  • La classe enfant recoit automatiquement toutes les methodes de la classe parente (y compris init).
  • Une methode redefinie dans l'enfant remplace celle du parent (elle est prioritaire).
  • Si l'enfant ne redefinit pas une methode, celle du parent est utilisee automatiquement.
Voir l’exemple
classe Animal {
    fonc init(moi, nom){ moi.nom ~ nom }
    fonc parler(moi){ affi(moi.nom, |fait un bruit.|) }
}
classe Chien herite Animal {
    fonc parler(moi){ affi(moi.nom, |aboie.|) }
}
c ~ Chien(|Rex|)
c.parler()   ->   Rex aboie.

parent

parent.methode(moi, ...)
  • Appelle la version d'une methode definie par la classe PARENTE (equivalent de super().methode(...) en Python).
  • Utilisable uniquement a l'interieur d'une methode d'une classe qui herite d'une autre (herite).
  • moi doit toujours etre passe en premier argument, comme pour n'importe quel appel de methode.
  • Utile pour garder le comportement du parent tout en ajoutant quelque chose en plus, au lieu de tout reecrire.
Voir l’exemple
classe Animal {
    fonc parler(moi){ affi(moi.nom, |fait un bruit.|) }
}
classe Chien herite Animal {
    fonc parler(moi){
        parent.parler(moi)
        affi(|(en particulier : aboie)|)
    }
}

moi

moi
  • A l'interieur d'une methode de classe, designe l'instance elle-meme (comme self en Python).
  • Doit etre le premier parametre de chaque fonc declaree dans une classe.
  • moi.attribut lit ou (avec ~) ecrit un attribut de l'instance courante.
Voir l’exemple
classe Compteur {
    fonc init(moi){ moi.n ~ 0 }
    fonc plus1(moi){ moi.n ~ moi.n + 1 }
}

conver.source.cible (durees/tailles)

conver.source.cible(valeur)
  • Convertit une valeur d'une unite vers une autre.
  • Temps : ms, seconde, minute, heure, jour. La seconde est l'unite de reference.
  • Tailles : octet, Ko, Mo, Go, Tera. Conversions binaires : 1 Ko = 1024 octets.
  • La conversion fonctionne dans les deux sens et peut donner un resultat fractionnaire (aucun arrondi, meme quand ca ne tombe pas juste).
Voir l'exemple
conver.minute.seconde(5)  ->  300
conver.heure.seconde(2)    ->  7200
conver.ms.seconde(500)     ->  0.5
conver.seconde.heure(3600)  ->  1
conver.jour.heure(1)       ->  24
conver.octet.Ko(1024)      ->  1
conver.Mo.Ko(1)            ->  1024

conver.ms.date · conver.date.ms

conver.ms.date(valeur) / conver.date.ms(texte)
  • conver.ms.date(valeur) : convertit un horodatage brut en millisecondes (epoch, ex: celui renvoye par temps()) en date/heure lisible "JJ/MM/AAAA HH:MM:SS". La valeur doit etre un nombre positif ou nul.
  • conver.date.ms(texte) : l'inverse -- convertit un texte "JJ/MM/AAAA HH:MM:SS" en horodatage brut en millisecondes. Format STRICT : erreur directe si le texte n'est pas exactement dans ce format, ou si la date n'existe pas dans le calendrier (ex: 31/02/2026), sans tentative de correction.
Voir l'exemple
conver.ms.date(0)  ->  |01/01/1970 01:00:00|
conver.date.ms(|01/01/1970 01:00:00|)  ->  0

attendre

attendre(secondes)
  • Suspend l'exécution du script pendant la durée indiquée, éventuellement fractionnaire.
  • L'attente ne bloque pas l'application et ne consomme pas le processeur pendant la durée d'attente.
  • Elle est interrompue si l'exécution du script est arrêtée depuis l'interface de l'application.
Voir l’exemple
affi(|Début|)
attendre(2)
affi(|2 secondes plus tard|)

secondesJusquaProchain

secondesJusquaProchain(jourSemaine, heure, minute)
  • Calcule le nombre de secondes à attendre avant la prochaine occurrence du jour de semaine (1=lundi..7=dimanche) et de l'heure:minute donnés. Si le moment cible est déjà passé (ou en cours) aujourd'hui, calcule jusqu'à la semaine suivante.
  • Conçu pour être combiné avec attendre() : déclenche une action exactement une fois par occurrence, sans boucle active ni drapeau de déduplication.
  • Limite : ne fonctionne que pendant que le script tourne activement (voir planifier() pour un rappel fiable même app fermée).
Voir l’exemple
tanqer(VRAI){
  attendre(secondesJusquaProchain(1, 9, 0))
  affi(|Lundi 9h : debut de semaine|)
}

planifier

planifier(jourSemaine, heure, minute, message)
  • Programme une notification système Android pour la prochaine occurrence du créneau.
  • Ne bloque pas le script : l'alarme reste active même après la fin du script et peut se reprogrammer chaque semaine.
  • Nécessite l'application native et les permissions Android nécessaires.
Voir l’exemple
planifier(1, 9, 0, |Lundi 9h : début de semaine|)

annuler.planifier

annuler.planifier(jourSemaine, heure, minute)
  • Annule l'alarme précédemment programmée sur le créneau indiqué.
Voir l’exemple
annuler.planifier(1, 9, 0)

planifier.liste

planifier.liste()
  • Renvoie toutes les alarmes actuellement programmees, sous forme de vecteur de liste(jourSemaine, heure, minute, message).
  • Pratique pour retrouver un creneau exact avant de l'annuler, sans avoir a le connaitre par coeur.
  • Necessite l'application native.
Voir l'exemple
pou(a dan planifier.liste()){
    affi(a[0], |/|, a[1], |:|, a[2], | - |, a[3])
}

annuler.planifier.parMessage

annuler.planifier.parMessage(texte)
  • Annule directement toutes les alarmes dont le message est exactement "texte" (il peut y en avoir plusieurs, sur des creneaux differents).
  • Renvoie le nombre d'alarmes annulees.
Voir l'exemple
n~annuler.planifier.parMessage(|Reunion|)
affi(n, | alarme(s) annulee(s)|)

annuler.tout.planifier

annuler.tout.planifier()
  • Annule d'un coup TOUTES les alarmes programmees.
  • Renvoie le nombre d'alarmes annulees.
Voir l'exemple
annuler.tout.planifier()

arreter.service.arriere

arreter.service.arriere()
  • Arrete le service qui execute les scripts en arriere-plan (celui lance automatiquement a l'ouverture de l'app, utilise par le bouton FOND).
  • Appelee dans un script lance via FOND (donc en train de tourner DANS le service) : ne fait que demander l'arret -- le script continue jusqu'a sa fin naturelle, le service s'arrete SEULEMENT APRES, une fois le resultat publie. Si le script plante avant cette ligne, le service reste actif.
  • Appelee depuis l'editeur (script lance avec RUN, donc localement, pas dans le service) : arrete le service immediatement.
  • Ne prend aucun argument, ne renvoie rien d'utile.
Voir l'exemple
** dans un script envoye au service (bouton FOND) :
affi(|traitement termine|)
arreter.service.arriere()
** le service s'arrete juste apres avoir publie ce resultat

envoyer.notif

envoyer.notif(...)
  • Affiche immediatement une notification système Android contenant le message donne.
  • Comme affi(), plusieurs elements separes par une virgule (,) peuvent etre combines dans le message.
  • La notification reste visible apres la fin du script et peut etre touchee pour rouvrir MonLangage.
  • Renvoie VRAI si Android accepte la notification, FAUX sinon.
  • Nécessite l'application native et, sur Android 13+, l'autorisation d'afficher des notifications (demandée automatiquement au premier appel si besoin).
Voir l’exemple
envoyer.notif(|Nouveau message recu|)
envoyer.notif(|Score :|, score, |points|)

connexion.disponible() / type.connexion()
  • connexion.disponible() : VRAI si une connexion internet (wifi ou data mobile) est active MAINTENANT, FAUX sinon.
  • Ne surveille rien en arriere-plan -- a verifier dans une boucle (tanqer/attendre) pour reagir a un changement de connexion.
  • type.connexion() : "wifi", "mobile", "ethernet", "autre" ou "aucune".
  • Necessite l'application native, aucune permission a accorder.
Voir l'exemple
tanqer VRAI{

        affi(|Connecte en |, type.connexion())

    }

niveau.batterie() / batterie.encharge()

  • batterie.encharge() : VRAI si le telephone est en train de charger (cable ou sans fil) ou deja completement charge.
  • Necessite l'application native, aucune permission a accorder.
Voir l'exemple
si(niveau.batterie() < 20 et non batterie.encharge()){

sms.recus · envoyer.sms

sms.recus(depuisSecondes) / envoyer.sms(numero, message[, sim])
  • sms.recus(depuisSecondes) : liste des SMS recus au cours des "depuisSecondes" dernieres secondes, chacun en liste(numero, message, date), le plus recent en premier. Attention : les indices commencent a 1 (msg[1] = numero, msg[2] = message, msg[3] = date). La date est deja lisible, au format JJ/MM/AAAA HH:MM:SS (conver.date.ms(...) la convertit en millisecondes si besoin).
  • Ne surveille rien en arriere-plan -- a verifier dans une boucle pour reagir a un SMS recu.
  • envoyer.sms(numero, message[, sim]) : envoie un SMS et attend le resultat reel de l'envoi (jusqu'a 15 secondes) : VRAI si le systeme confirme l'envoi, FAUX sinon. Le troisieme parametre optionnel sim vaut 1 ou 2 pour choisir directement la SIM (Android demande alors l'autorisation de lire l'etat du telephone). Les messages longs sont automatiquement decoupes en plusieurs parties, recus comme un seul message chez le destinataire.
  • Necessite l'application native et les permissions de lecture/envoi de SMS -- demandees automatiquement si besoin (a accorder puis relancer le script).
  • Android peut demander une confirmation supplementaire si trop de SMS partent d'un coup vers trop de destinataires differents en peu de temps (protection systeme anti-spam).
Voir l'exemple
pou(msg dan sms.recus(60)){
    si(msg[2] == |stop|){
        envoyer.sms(msg[1], |Bien recu, arret confirme.|)
    }
}

ouvrir.whatsapp() / ouvrir.whatsapp(numero, message) / messenger.ouvrir(destinataire, message)
  • Ouvre WhatsApp (ou Messenger) sur la conversation avec ce destinataire, texte deja rempli dans le champ de saisie.
  • IMPORTANT : Android n'autorise pas une app tierce a appuyer sur Envoyer a la place de l'utilisateur dans une autre app -- contrairement a envoyer.sms(), c'est donc un RACCOURCI (l'app s'ouvre prete a envoyer), pas un envoi automatique complet.
  • ouvrir.whatsapp : destinataire = numero de telephone avec indicatif pays (ex: 33612345678, sans le 0 initial).
  • messenger.ouvrir : destinataire = NOM D'UTILISATEUR Facebook (pas un numero -- Messenger n'identifie pas les gens par numero comme WhatsApp).
  • Necessite l'application native et une connexion internet (verifiable avant avec connexion.disponible()).
Voir l'exemple
si(connexion.disponible()){
    ouvrir.whatsapp(|33612345678|, |Salut !|)
} sinon {
    envoyer.sms(|33612345678|, |Salut !|)
}

Creer un vecteur/une matrice

c

c(a, b, c, ...)
  • Construit un vecteur a partir des valeurs donnees.
  • Si on lui donne un vecteur ou une matrice en argument, il en reprend tous les elements.
  • Unifie tout vers un seul type (texte > nombre > booleen) : pas de melange de types, contrairement a liste().
Voir l’exemple
c(1,2,3)          ->   [1] 1 2 3
c(|a|,|b|)        ->   [1] "a" "b"

liste

liste(a, b, c, ...)
  • Construit une liste a partir des valeurs donnees, accessible par indice comme un vecteur (maliste[i]).
  • Contrairement a c(), ne fusionne pas les vecteurs/matrices/listes donnes en argument et n'unifie PAS les types : chaque element garde son type d'origine (nombre, texte, booleen, vecteur, instance...).
  • Ecriture indexee possible : maliste[i]~valeur (ou moi.maliste[i]~valeur pour un attribut).
  • maliste.ajout(...) et maliste.supri(...) fonctionnent comme sur un vecteur, sans fusion ni unification.
Voir l’exemple
l ~ liste(1, |bonjour|, VRAI, c(1,2,3))
affi(l[1])   ->   1
affi(l[2])   ->   bonjour
l[1] ~ |change|

dictionnai · lire · cles · valeurs

dictionnai(|cle|: valeur, ...) / d[cle] / d.lire(cle, defaut) / d.cles() / d.valeurs() / d.supri(cle)
  • Construit un dictionnai : des valeurs rangees sous des cles (du texte ou des nombres), comme un dict Python. Chaque element s'ecrit cle: valeur, avec deux-points entre les deux.
  • Les valeurs peuvent etre de n'importe quel type (nombre, texte, liste, autre dictionnai, instance...). L'ordre d'ajout est conserve.
  • d[cle] lit une valeur : si la cle n'existe pas, erreur CleIntrouvable. d[cle]~valeur ecrit : la cle est creee si elle n'existe pas (d[cle][i]~valeur pour modifier l'interieur d'une valeur).
  • d.lire(cle, defaut) lit sans erreur : renvoie defaut si la cle est absente (sans rien ajouter), ou pasdefini si defaut est omis.
  • d.cles() et d.valeurs() renvoient une liste. d.supri(cle) retire une cle (erreur si elle n'existe pas) et s'ecrit seul sur sa ligne.
  • cle dan d : VRAI si la cle existe. pou(c dan d){...} parcourt les cles. lon(d) donne le nombre de cles. copier(d) / copier.profond(d) copient le dictionnai.
  • affi(d) affiche le dictionnai sur une ligne s'il est court, et une entree par ligne s'il est long (plus d'environ 40 caracteres).
  • Un dictionnai se sauvegarde avec ecrire.cle(...) / ecrire.fichier(...) comme une liste. est.dictionnai(var) teste le type, natu(var) renvoie dictionnai.
Voir l’exemple
d ~ dictionnai(|nom|: |Yannick|, |age|: 30)
affi(d[|nom|])                 ->   Yannick
d[|ville|] ~ |Abidjan|         ** cree la cle
affi(d.lire(|pays|, |?|))      ->   ?
si(|age| dan d){ affi(d[|age|]) }
pou(c dan d){ affi(c, d[c]) }
** compter des mots :
compte ~ dictionnai()
pou(mot dan liste(|a|,|b|,|a|)){ compte[mot] ~ compte.lire(mot, 0) + 1 }

seq

seq(debut, fin, pas)
  • Construit une suite de nombres, de debut a fin.
  • pas est facultatif : +1 par defaut (ou -1 si fin est plus petit que debut).
Voir l’exemple
seq(1,10,2)   ->   [1] 1 3 5 7 9

rep

rep(elements, nombre)
  • Repete des elements a la suite, nombre fois.
  • elements peut etre une seule valeur ou un vecteur entier.
Voir l’exemple
rep(c(1,2),3)   ->   [1] 1 2 1 2 1 2

alea

alea(var, x) ou alea(debut, fin, x)
  • alea(var, x) : choisit x elements au hasard, sans remise, parmi un vecteur ou une matrice.
  • alea(debut, fin, x) : choisit x nombres entiers au hasard, sans remise, dans l'intervalle [debut, fin] (bornes incluses).
  • Renvoie toujours un vecteur, meme pour x~1.
  • x ne peut pas depasser le nombre d'elements disponibles (pas de remise = jamais deux fois la meme valeur).
Voir l’exemple
alea(1,49,6)         ->   6 numeros distincts entre 1 et 49
alea(c(10,20,30),2)  ->   2 valeurs distinctes parmi le vecteur

ralea

ralea(var, x) ou ralea(debut, fin, x)
  • Comme alea(...), mais AVEC remise : un meme element/nombre peut sortir plusieurs fois.
  • x peut donc depasser le nombre d'elements disponibles (contrairement a alea()).
Voir l’exemple
ralea(1,6,10)          ->   10 lancers de de a 6 faces (repetitions possibles)
ralea(c(|pile|,|face|),5)  ->   5 tirages a pile ou face

:

debut:fin
  • Raccourci rapide pour creer une suite de nombres entiers, avec un pas de 1.
  • Si fin est plus petit que debut, compte a l'envers (pas de -1).
Voir l’exemple
1:5   ->   [1] 1 2 3 4 5
5:1   ->   [1] 5 4 3 2 1

lettr

lettr
  • Identifiant constant (sans parentheses, comme VRAI/FAUX) qui vaut un vecteur contenant les 26 lettres de l'alphabet, en minuscule, de "a" a "z".
Voir l’exemple
lettr   ->   [1] "a" "b" "c" ... "z"
x ~ lettr
pou(l dan lettr){ affi(l) }

Lettr

Lettr
  • Identifiant constant (sans parentheses, comme VRAI/FAUX) qui vaut un vecteur contenant les 26 lettres de l'alphabet, en majuscule, de "A" a "Z".
Voir l’exemple
Lettr   ->   [1] "A" "B" "C" ... "Z"

matrice

matrice(elements, nlig~..., ncol~..., parlig~VRAI ou FAUX)
  • Construit une matrice a partir d'une liste d'elements.
  • nlig et ncol : un seul des deux suffit, l'autre est calculer automatiquement.
  • parlig~VRAI remplit ligne par ligne. Par defaut (parlig~FAUX), le remplissage se fait colonne par colonne.
Voir l’exemple
matrice(1:6, nlig~2, ncol~3)

trans

trans(m)
  • Renvoie la transposee d'une matrice : les lignes deviennent des colonnes et inversement.
  • Une matrice nlig x ncol devient une matrice ncol x nlig.
Voir l’exemple
m ~ matrice(1:6, nlig~2, ncol~3)
trans(m)   ->   une matrice 3x2

inverse

inverse(m)
  • Renvoie l'inverse d'une matrice carree (celle telle que m .. inverse(m) donne la matrice identite).
  • La matrice doit etre carree (autant de lignes que de colonnes).
  • Erreur si la matrice n'est pas inversible (determinant nul, comme det(m)==0).
Voir l’exemple
m ~ matrice(c(4,2,7,6), nlig~2, ncol~2)
inverse(m)   ->   une matrice 2x2
m..inverse(m)   ->   la matrice identite

Voir l’exemple

|bonjour|.lon()   ->   7
|  salut  |.suprespac().lon()   ->   5

Voir l’exemple
dim(matrice(1:6, nlig~2))   ->   [1] 2 3

som

som(v)

Voir l’exemple
som(c(1,2,3))   ->   6

moy(v)

Voir l’exemple
moy(c(1,2,3))   ->   2

Voir l’exemple

max

max(v) / max(a, b, ...)
  • Renvoie le plus grand element, parmi un ou plusieurs arguments (nombres, vecteurs et/ou matrices confondus).
Voir l’exemple

max(3, 7, c(1,9))   ->   9

min

min(v) / min(a, b, ...)
  • Renvoie le plus petit element, parmi un ou plusieurs arguments (nombres, vecteurs et/ou matrices confondus).
Voir l’exemple
min(c(3,7,2))   ->   2

suchaq

suchaq(matrice, marge, fonction)
  • Comme apply() en R : applique 'fonction' a chaque ligne (marge~1) ou chaque colonne (marge~2) d'une matrice.
  • 'fonction' : som, moy, var, sd, max, min (sans parentheses), ou n'importe quelle valeur-fonction -- nom d'une fonction definie avec fonc, variable qui en contient une, fonction anonyme fonc(x){...}.
  • Renvoie un vecteur (un resultat par ligne/colonne) si 'fonction' renvoie un nombre.
  • Renvoie une matrice si 'fonction' renvoie un vecteur (une colonne de resultat par ligne/colonne d'origine).
Voir l’exemple

det(m)

  • La matrice doit etre carree (autant de lignes que de colonnes).
Voir l’exemple

trace(m)

  • La matrice doit etre carree (autant de lignes que de colonnes).
Voir l’exemple
trace(matrice(c(2,0,0,3), nlig~2, ncol~2))   ->   5

Acceder / modifier un element

[ · ]

v[i] / m[ligne,colonne]
  • Lit un ou plusieurs elements d'un vecteur (v[i]) ou d'une matrice (m[ligne,colonne]).
  • Fonctionne aussi sur un texte, en lecture et en ecriture : t[1] est le premier caractere, t[1]~|B| le remplace.
  • Crochets enchaines pour ecrire a l'interieur d'une liste : l[i][j] ~ valeur (liste de listes), l[2][1] ~ 99 (liste de vecteurs), moi.grille[i][j] ~ v. Chaque indice avant le dernier doit designer un element existant d'une liste (erreur claire sinon).
  • Les indices commencent a 1 (pas a 0).
  • Un indice laisse vide signifie 'tout' : m[,2] = toute la colonne 2, m[3,] = toute la ligne 3.
  • L'indice peut aussi etre un vecteur d'indices (c(2,5) ou 2:4) pour en selectionner plusieurs a la fois.
  • L'indice peut etre un vecteur logique (issu d'une comparaison) pour selectionner selon une condition.
  • Peut aussi servir a modifier : v[2:4] ~ c(0,0,0), B[,4] ~ c(0,0,0), B[B>15] ~ 0, etc.
  • Agrandissement automatique : v[8] ~ x ou B[5,5] ~ x avec un indice au-dela de la taille actuelle etend le vecteur/la matrice, les nouvelles cases etant remplies de 0.
Voir l’exemple
v[2]         ->   2e element
v[2:4]       ->   du 2e au 4e element
v[c(2,5)]    ->   le 2e et le 5e element
v[v>3]       ->   les elements superieurs a 3
B[2:4,]      ->   les lignes 2 a 4, toutes les colonnes
B[,2:5]      ->   toutes les lignes, les colonnes 2 a 5
B[B==5]      ->   tous les elements de B qui valent 5
B[B>15] ~ 0  ->   remplace par 0 tous les elements > 15
v[7] ~ 9     ->   agrandit v a 7 elements (0 pour les cases vides) puis met 9 en 7e position

ajout

nom.ajout(elements)
  • Ajoute de nouveaux elements a un vecteur ou une matrice qui existe deja, sans supprimer ce qu'il contenait.
  • Pour une matrice, les elements sont ajoutes comme nouvelle(s) colonne(s).
Voir l’exemple
v.ajout(4,5)
m.ajout(9,9)

trier

trier(l, decroiss~, cle~) / l.trier(decroiss~, cle~)
  • trier(l) renvoie une NOUVELLE liste (ou un nouveau vecteur) trie par ordre croissant : l reste intacte (comme sorted() en Python).
  • l.trier() trie l ELLE-MEME, sur place, et ne renvoie rien (comme list.sort() en Python) : a ecrire seul sur sa ligne.
  • decroiss~VRAI trie du plus grand au plus petit. cle~fonction trie selon la valeur que la fonction calcule pour chaque element (ex: cle~fonc(x) x[2]).
  • Le tri est stable : deux elements egaux gardent leur ordre. On trie des nombres, ou du texte (ordre des caracteres : les majuscules passent avant les minuscules), mais pas un melange des deux : utilise cle~ pour comparer des valeurs du meme type (ex: cle~fonc(x) x.miniscul()).
Voir l’exemple
l ~ liste(3,1,2)
m ~ trier(l)                    ** m = 1,2,3  et l inchangee
l.trier(decroiss~VRAI)          ** l = 3,2,1
p ~ liste(liste(|b|,2), liste(|a|,1))
q ~ trier(p, cle~fonc(x) x[2])  ** trie selon le 2e element

copier · copier.profond

copier(x) / copier.profond(x)
  • Une liste (ou un dictionnai, une instance) copiee avec b~a reste LA MEME : modifier b modifie a. Pour avoir une vraie copie independante, utilise copier.
  • copier(x) copie la liste, le vecteur, la matrice, le dictionnai ou l'instance, mais les listes/dictionnai places A L'INTERIEUR restent partages avec l'original.
  • copier.profond(x) copie tout, a tous les niveaux : plus aucun element n'est partage avec l'original.
Voir l’exemple
a ~ liste(liste(1,2), 3)
b ~ copier(a)
b[2] ~ 7                  ** a[2] reste 3
b[1][1] ~ 99              ** a[1][1] devient aussi 99 (liste interne partagee)
c ~ copier.profond(a)
c[1][1] ~ 5               ** a n'est pas touche

supri

nom.supri(elements)
  • Supprime des elements d'un vecteur ou d'une matrice qui existe deja (inverse de .ajout()).
  • Pour un vecteur : supprime, pour chaque valeur donnee, sa premiere occurrence trouvee.
  • Pour une matrice : les elements donnes (par groupe de nlig, comme pour .ajout()) doivent correspondre exactement a une colonne existante, qui est alors supprimee.
  • Pour un dictionnai : d.supri(cle) retire la cle et sa valeur (erreur CleIntrouvable si elle n'existe pas).
Voir l’exemple
v~c(2,3,2,5)
v.supri(2,3)     ->   reste c(2,5)
v~c(|rea|,|r|,|e|)
v.supri(|rea|)   ->   reste c(|r|,|e|)
v.supri(v[1])    ->   supprime la valeur en 1ere position

Operateurs

+

a + b
  • Additionne deux nombres, deux vecteurs de MEME longueur (element par element) ou deux matrices de memes dimensions.
  • Nombre + vecteur (ou vecteur + nombre) : le nombre est ajoute a chaque element. Nombre + matrice (ou matrice + nombre) : erreur claire ; ajoute plutot une matrice de memes dimensions.
  • Deux vecteurs de longueurs differentes : erreur claire (pas de repetition automatique).
  • Si au moins un des deux cotes est du TEXTE (|23| ou | a|, meme s'il ressemble a un nombre), + CONCATENE : |a| + |b| donne ab, |n=| + 5 donne n=5, 1 + |a| donne 1a. Un nombre, VRAI/FAUX ou pasdefini est converti en texte.
  • Sans aucun texte, c'est l'addition normale : |23| + 1 donne 231, mais 23 + 1 donne 24.
  • LISTES : liste + liste concatene (liste(1,2) + liste(3) donne liste(1,2,3)) ; liste + valeur seule (nombre, texte, VRAI/FAUX, vecteur, dictionnai...) ajoute la valeur comme UN element a la fin, valeur + liste l'ajoute au debut. Le resultat est une NOUVELLE liste, entierement independante des operandes (rien n'est partage).
  • Erreur claire aussi pour : du texte avec un vecteur ou une matrice, un vecteur/une matrice qui contient du texte ou des elements imbriques, un dictionnai ou une instance (utilise texte(...) pour les coller dans un texte).
Voir l’exemple
c(1,2,3) + c(10,20,30)   ->   [1] 11 22 33
c(1,2,3) + 10   ->   [1] 11 12 13
|trouve a | + 5   ->   trouve a 5
|23| + 1   ->   231
23 + 1   ->   24
liste(1,2) + liste(3)   ->   liste(1,2,3)
liste(1,2) + 3   ->   liste(1,2,3)
0 + liste(1,2)   ->   liste(0,1,2)
liste(1) + |a|   ->   liste(1,a)
liste(1) + c(5,6)   ->   la liste, puis le vecteur comme un seul element

-

a - b
  • Soustrait deux nombres, deux vecteurs de MEME longueur (element par element) ou deux matrices de memes dimensions.
  • Nombre - vecteur ou vecteur - nombre : applique a chaque element. Nombre et matrice (dans un sens ou dans l'autre) : erreur claire.
  • Avec du texte (texte - nombre, nombre - texte, texte - texte) : erreur claire. La soustraction ne marche qu'entre nombres.
  • Deux vecteurs de longueurs differentes, un vecteur/une matrice qui contient du texte, une liste : erreur claire (voir +). Pour retirer un element d'une liste, utilise l.supri(...).
Voir l’exemple
c(10,20,30) - c(1,2,3)   ->   [1] 9 18 27
10 - c(1,2)   ->   [1] 9 8
|a| - 1   ->   erreur : impossible de soustraire avec du texte

*

a * b
  • Multiplie deux nombres.
  • Nombre * vecteur (ou vecteur * nombre) : chaque element est multiplie. Vecteur * vecteur : produit element par element (meme longueur obligatoire, sinon erreur claire).
  • Nombre * matrice (ou matrice * nombre) : chaque element est multiplie.
  • Matrice * matrice : erreur claire. Il existe un operateur dedie, .. (produit matriciel). Pour le produit scalaire de deux vecteurs, utilise l'operateur .
  • texte * nombre (ou nombre * texte) REPETE le texte : |ab| * 3 donne ababab. Le nombre doit etre un entier positif ou nul (0 donne un texte vide). texte * texte : erreur claire.
  • liste * nombre (ou nombre * liste) REPETE la liste : liste(1,2) * 2 donne liste(1,2,1,2). Meme regle pour le nombre ; chaque repetition est une copie independante. liste * liste : erreur claire.
  • Un vecteur/une matrice qui contient du texte ou des elements imbriques : erreur claire (voir +).
Voir l’exemple
3 * 4   ->   12
c(1,2,3) * 2   ->   [1] 2 4 6
c(1,2) * c(3,4)   ->   [1] 3 8
|ab| * 3   ->   ababab
3 * |-|   ->   ---
liste(1,2) * 2   ->   liste(1,2,1,2)

/

a / b
  • Divise deux nombres.
  • Nombre / vecteur, vecteur / nombre et vecteur / vecteur (meme longueur) : element par element. Matrice / nombre : chaque element est divise par le nombre.
  • Nombre / matrice et matrice / matrice : erreur claire. Pour utiliser l'inverse d'une matrice, utilise inverse(m) : 2 * inverse(m), ou m1 .. inverse(m2).
  • Avec du texte (nombre / texte, texte / nombre, texte / texte) : erreur claire. Il en va de meme pour % (reste), ENTI (division entiere) et ^ (puissance) : ils ne marchent qu'entre nombres.
  • Un vecteur/une matrice qui contient du texte ou des elements imbriques, une liste : erreur claire (voir +).
Voir l’exemple
10 / 4   ->   2.5
c(2,4) / 2   ->   [1] 1 2
8 / c(2,4)   ->   [1] 4 2
m / 2   ->   chaque element de m divise par 2

%

a % b
  • Renvoie le reste de la division entiere de a par b.
Voir l’exemple
7 % 2   ->   1

.

v1 . v2
  • Calcule le produit scalaire entre deux vecteurs de meme taille.
  • Multiplie les elements un par un puis additionne le tout : le resultat est un seul nombre.
  • Un vecteur qui contient du texte, une liste : erreur claire. C'est l'operateur du produit scalaire : .. est reserve au produit matriciel entre matrices.
Voir l’exemple
c(1,2,3) . c(4,5,6)   ->   32

×

v1 × v2
  • Calcule le produit vectoriel entre deux vecteurs.
  • Fonctionne uniquement pour des vecteurs de taille 3 (comme en geometrie dans l'espace).
Voir l’exemple
c(1,0,0) × c(0,1,0)   ->   [1] 0 0 1

..

m1 .. m2
  • Multiplie deux matrices selon les regles du produit matriciel (pas element par element).
  • Le nombre de colonnes de m1 doit etre egal au nombre de lignes de m2.
  • Entre deux VECTEURS, .. donne une erreur claire : pour leur produit scalaire, utilise l'operateur . (v1 . v2). Une liste, ou une matrice qui contient du texte : erreur claire.
Voir l’exemple
m1 .. m2

^

a ^ b
  • Puissance : a a la puissance b.
  • Fonctionne aussi element par element sur les vecteurs, avec recyclage comme + et -.
  • Sur une matrice carree, avec un exposant entier positif ou nul : vraie puissance matricielle (m^3 = m..m..m, m^0 = matrice identite). Exposant negatif ou non entier, matrice non carree ou matrice^matrice : erreur claire (utilise inverse(m) pour l'inverse).
Voir l’exemple
2 ^ 3   ->   8
c(1,2,3) ^ 2   ->   [1] 1 4 9
m ^ 2   ->   m .. m   (m carree)

ENTI

a ENTI b
  • Division entiere : divise a par b et ne garde que la partie entiere (arrondi vers le bas).
  • Fonctionne aussi element par element sur les vecteurs et les matrices.
Voir l’exemple
7 ENTI 2   ->   3
c(7,9,11) ENTI 2   ->   [1] 3 4 5

MOD

a MOD b
  • Renvoie le reste de la division entiere de a par b (equivalent a %).
  • Fonctionne aussi element par element sur les vecteurs et les matrices.
Voir l’exemple
7 MOD 2   ->   1
c(7,9,11) MOD 2   ->   [1] 1 1 1

dan

var1 dan var2
  • Teste si var1 se trouve dans var2.
  • Si var2 est un vecteur ou une matrice : renvoie un vecteur/une matrice de VRAI/FAUX, un par position (comme %in% en R), pour reperer a quelle(s) position(s) var1 se trouve.
  • Si var2 est une suite de caracteres (texte) : renvoie un simple VRAI/FAUX selon que var1 apparait comme sous-chaine dans var2.
  • var1 doit etre une valeur simple (pas un vecteur/une matrice).
  • Utilise dans si(...), VRAI si var1 se trouve a au moins une position.
Voir l’exemple
2 dan c(2,3,4)   ->   [1] VRAI FAUX FAUX
|mot| dan |un mot|   ->   VRAI

== · != · < · > · <= · >=

a == b / a != b / a < b / a > b / a <= b / a >= b
  • Compare deux valeurs et renvoie VRAI ou FAUX.
  • == egalite, != difference, < strictement inferieur, > strictement superieur, <= inferieur ou egal, >= superieur ou egal.
  • Fonctionne aussi element par element sur les vecteurs et les matrices (renvoie alors un vecteur/une matrice de VRAI/FAUX), avec recyclage comme + et -.
Voir l’exemple
3 == 3   ->   VRAI
c(1,2,3) > 2   ->   [1] FAUX FAUX VRAI

et · ou

condition1 et condition2 / condition1 ou condition2
  • Combine deux conditions booleennes.
  • et : VRAI seulement si les deux conditions sont vraies.
  • ou : VRAI si au moins une des deux conditions est vraie.
  • Utilises typiquement dans si(...), tanqer(...), sision(...).
  • Court-circuit comme en Python : le cote droit n'est PAS evalue si le cote gauche suffit (et : gauche FAUX ; ou : gauche VRAI). Le resultat reste toujours VRAI ou FAUX (jamais l'operande brut).
  • Garde typique : x!=0 et 10/x>2 ne divise jamais par zero quand x vaut 0.
Voir l’exemple
si(x>0 et x<10){ affi(|entre 0 et 10|) }
si(jour==|samedi| ou jour==|dimanche|){ affi(|weekend|) }

non

non condition
  • Negation logique : VRAI devient FAUX et inversement.
  • Plus fort que et/ou, et s'applique a toute la comparaison qui suit : non x>5 equivaut a non(x>5).
  • Fonctionne avec dan : non 3 dan c(1,2) renvoie VRAI.
Voir l’exemple
si(non fichier_present){ affi(|absent|) }
non x>5 et x<10   ->   (non(x>5)) et (x<10)

cos(x)

exp(x)

Constantes

VRAI · FAUX

VRAI / FAUX
  • Les deux seules valeurs booleennes (vrai / faux) du langage.
  • Utiles dans les conditions (si, tanqer) et pour le parametre parlig de matrice().
Voir l’exemple
si(3>2){ affi(VRAI) }

pasdefini

pasdefini
  • La valeur "pas definie" du langage (comme VRAI/FAUX, mais pour l'absence de valeur).
  • C'est ce que renvoie un retour sans valeur (ou l'absence de retour) dans une fonction perso.
  • Utilisable dans une comparaison : si(x == pasdefini){ ... }.
Voir l’exemple
fonc f(){ retour }
f()   ->   pasdefini

saulig

affi(..., saulig, ...) / ecrire.cle(cle, ..., saulig, ...) / c(..., saulig, ...)
  • Saut de ligne : un texte contenant un seul caractere retour a la ligne.
  • Dans affi()/entr(), insere un retour a la ligne a cet endroit dans le message affiche/demande.
  • Utilisable aussi comme valeur ordinaire partout ou une valeur brute est attendue : ecrire.cle(...), ecrire.fichier(...), ajout.cle(...), ajout.fichier(...), c(...), liste(...), matrice(...).
  • Doit toujours apparaitre SEUL comme argument (jamais colle a l'interieur d'un |texte|, sinon ce n'est plus reconnu -- ce serait alors juste le mot 'saulig' litteral).
  • Pour un saut de ligne a l'interieur d'un texte, on peut aussi ecrire \n (voir echappement).
  • Pour une ligne vide toute seule dans affi(), on peut aussi ecrire affi(||) ou affi( | |).
Voir l’exemple
affi(|Programme de calcul|, saulig, |----------|)
ecrire.cle(|notes|, |Titre|, saulig, |Sous-titre|)   ** liste() : "Titre", "\n", "Sous-titre" **

Texte

texte

texte(a, b, ...)
  • Concatene plusieurs parties en UN SEUL texte, exactement comme les arguments de affi()/entr()/~ (avec |texte| et saulig pour un saut de ligne).
  • Contrairement a affi(), ne s'affiche pas : renvoie le texte concatene comme une valeur, utilisable dans une expression.
  • Utile pour construire un texte a passer en UN SEUL argument a ecrire.cle(...), ecrire.fichier(...) ou ajout.cle(...) -- qui, eux, rangent chaque argument separe par une virgule comme un element distinct d'une liste() plutot que de les coller ensemble.
Voir l’exemple
ligne ~ texte(|+ Depot: |, montant, | F|, saulig)
ecrire.fichier(|/sdcard/historique.mld|, h + ligne)

echappement · antislash · r|...| · f|...| · rf|...| · fr|...|

|texte\n| r|texte brut| f|texte {expression}| rf|...|
  • Dans un texte |...|, l'antislash \ introduit une sequence : \| une barre |, \\ un antislash, \n saut de ligne, \t tabulation, \r retour chariot, \s espace insecable, \uXXXX et \u{...} un caractere Unicode (\u00e9 donne e accent aigu, \u{1F600} donne un emoji).
  • Un antislash suivi d'un autre caractere (ex: \b) reste tel quel, sans avertissement. Le texte se ferme a la premiere barre NON echappee : un texte ne peut donc pas finir par un seul antislash, ecris \\ (|C:\\dossier\\|).
  • r|...| : texte BRUT, rien n'est interprete (\n reste \ puis n). Pratique pour un chemin : r|C:\nouveau\texte|. La barre \| ne ferme pas le texte mais garde ses deux caracteres.
  • f|...| : insere des valeurs. {expression} est remplace par sa valeur, affichee comme dans affi() : f|Total : {prix*qte} euros|. Toute expression est permise, y compris un appel de fonction avec des textes en arguments : f|{compte(|bob|)}|. Seul un texte |...| SEUL dans les accolades est une erreur : f|{|e|}| (les accolades servent a inserer une variable ou un resultat, pas un texte).
  • Accolade ecrite telle quelle dans un f|...| : {{ ou \{ pour {, }} ou \} pour }. Une accolade vide {} ou jamais fermee est une erreur, signalee avant l'execution.
  • Dans les accolades, \| n'est accepte qu'au tout debut ou a la toute fin ; il s'affiche tel quel autour de la valeur : f|{\|e\|}| affiche |5| si e vaut 5 (comme f|\|{e}\||). Au milieu (f|{a\|+b}|) c'est une erreur.
  • rf|...| et fr|...| combinent les deux : rf|C:\{dossier}\a.txt| garde les antislash et insere {dossier}. r, f, rf et fr doivent etre colles a la barre ouvrante ; une variable nommee r ou f reste utilisable (r ~ 5).
  • saulig reste valable : affi(|a|, saulig, |b|) revient a affi(|a\nb|).
Voir l’exemple
affi(|Ligne 1\nLigne 2|)
affi(|Il a dit : \|oui\||)
nom ~ |Yan|
age ~ 20
affi(f|{nom} a {age+1} ans|)
affi(r|C:\nouveau\texte|)
affi(f|{{x}} vaut {age}|)

miniscul · majuscul · suprespac

var.miniscul() / var.majuscul() / var.suprespac()
  • miniscul() convertit le texte contenu dans var en minuscules.
  • majuscul() convertit le texte contenu dans var en majuscules.
  • suprespac() supprime les espaces au debut et a la fin du texte.
  • Les parentheses peuvent contenir un espace : var.miniscul( ), var.majuscul( ) ou var.suprespac( ).
  • Les commandes peuvent etre enchainees dans l'ordre : var.miniscul().suprespac() ou var.majuscul().suprespac().
  • Elles s'enchainent aussi avec decoup, joindr, remplace, cherch, commence, termine, lon, avant, apres, entre, garder et enlever : var.suprespac().majuscul().decoup().
  • Sur une liste ou un vecteur, elles s'appliquent a chaque element texte (un seul niveau, les autres elements restent tels quels) : liste(|A|, |B|).miniscul() donne liste(|a|, |b|). Seule sur une ligne, l.majuscul() change seulement la variable l : une autre variable qui designait la meme liste (w ~ l) n'est pas modifiee.
Voir l’exemple
nom~|  BONJOUR  |
nom.miniscul().suprespac()
affi(nom)   ->   bonjour

decoup · joindr · remplace · cherch · commence · termine

texte.decoup(separateur) / texte.decoup(separateur, limite) / texte.decoup(limite) / liste.joindr(separateur) / texte.remplace(ancien, nouveau) / texte.remplace(ancien, nouveau, max) / x.cherch(morceau) / texte.commence(debut) / texte.termine(fin)
  • texte.decoup(sep) coupe le texte a chaque sep (n'importe quel texte, de n'importe quelle longueur) et renvoie une liste. Sans sep : coupe sur les espaces (plusieurs espaces de suite comptent pour un seul, ceux du debut et de la fin sont ignores). Avec sep vide || : coupe lettre par lettre. saulig est accepte comme argument : texte.decoup(saulig) coupe a chaque saut de ligne, liste.joindr(saulig) colle avec des sauts de ligne, texte.remplace(saulig, | |) enleve les sauts de ligne.
  • texte.decoup(sep, limite) fait au plus limite morceaux : le dernier garde tout le reste. texte.decoup(limite) fait pareil en coupant sur les espaces. Limite 0 ou negative : liste vide. Limite plus grande que le nombre de morceaux possibles : meme resultat que decoup(sep). Limite non entiere (2.5) : erreur claire. Un nombre seul est toujours la limite : pour couper sur un chiffre, l'ecrire en texte : decoup(|1|).
  • liste.joindr(sep) colle les elements d'une liste ou d'un vecteur avec sep entre chaque (sans sep : colles sans rien entre eux). Les nombres sont convertis en texte.
  • texte.decoup(motif) coupe a chaque endroit ou le motif correspond : |a1b22c|.decoup(m|\d+|) donne liste(|a|, |b|, |c|). Les groupes () du motif ne sont pas ajoutes aux morceaux. La limite marche comme pour un texte.
  • texte.remplace(ancien, nouveau) remplace TOUTES les occurrences de ancien par nouveau (ancien ne peut pas etre vide). Un 3e argument facultatif limite le nombre de remplacements (au plus max, les premiers) : |a a a|.remplace(|a|, |b|, 2) donne b b a. ancien peut aussi etre un motif (voir correspond / trouve) : nouveau peut alors contenir $1, $2... ou $<nom> pour reutiliser un groupe, et $$ pour un vrai $. Sur une liste ou un vecteur, remplace s'applique a chaque element texte et renvoie une liste.
  • x.cherch(morceau) donne la position (a partir de 1, comme texte[i]) de la premiere occurrence, ou 0 si le morceau est absent. x peut etre un texte (on cherche un morceau de texte) ou une liste/un vecteur (on cherche une valeur : l.cherch(5)).
  • texte.commence(debut) et texte.termine(fin) renvoient VRAI ou FAUX. Majuscules et minuscules comptent comme des lettres differentes.
  • Toutes ces commandes s'enchainent avec miniscul(), majuscul(), suprespac(), lon(), avant, apres, entre, garder et enlever : texte.suprespac().majuscul().decoup().joindr(|-|). Les anciennes ecritures decoup(texte, sep), joindr(liste, sep)... marchent toujours.
Voir l’exemple
|a, b, c|.decoup(|, |)         ->   liste(|a|, |b|, |c|)
|un deux  trois|.decoup()         ->   liste(|un|, |deux|, |trois|)
|un deux trois|.decoup(2)       ->   liste(|un|, |deux trois|)
|a,b,c,d|.decoup(|,|, 3)        ->   liste(|a|, |b|, |c,d|)
texte(|a|, saulig, |b|).decoup(saulig)   ->   liste(|a|, |b|)
liste(|a|,|b|).joindr(| et |)   ->   a et b
|le chat|.remplace(|chat|, |chien|)   ->   le chien
|bonjour|.cherch(|jou|)         ->   4
liste(|a|, 5).cherch(5)         ->   2
|bonjour|.commence(|bon|)       ->   VRAI
|  un deux  |.suprespac().decoup().joindr(|-|)   ->   un-deux

avant · apres

texte.avant(sep) / texte.avant(sep, position) / texte.avant(position) / texte.avant.dernier(sep) / texte.apres(sep) / texte.apres(sep, position) / texte.apres(position) / texte.apres.dernier(sep)
  • texte.avant(sep) renvoie tout ce qui est avant le PREMIER sep ; texte.apres(sep) renvoie tout ce qui est apres.
  • texte.avant(sep, n) et texte.apres(sep, n) coupent au n-ieme sep (n entier, a partir de 1, compte de gauche a droite sans chevauchement). Un nombre seul est la position : pour couper sur un chiffre, l'ecrire en texte : avant(|1|). Position non entiere : erreur claire.
  • texte.avant.dernier(sep) et texte.apres.dernier(sep) coupent au DERNIER sep. Pas de position : « dernier » la fixe (avant.dernier(sep) donne la meme chose que avant(sep, N) quand il y a N sep).
  • Sans sep (avant(n), avant.dernier()...), le separateur est les espaces, comme decoup() : ceux du debut et de la fin sont ignores, plusieurs espaces de suite comptent pour un seul.
  • Sep absent (ou position trop grande) : avant renvoie tout le texte, apres renvoie un texte vide. Position 0 ou negative : texte vide. Sep vide || : erreur claire.
  • Sur une liste ou un vecteur, elles s'appliquent a chaque element texte et renvoient une liste (un seul niveau, les autres elements restent tels quels).
Voir l’exemple
|a/b/c/d|.avant(|/|)              ->   a
|a/b/c/d|.avant(|/|, 2)          ->   a/b
|a/b/c/d|.apres(|/|)             ->   b/c/d
|a/b/c/d|.apres(|/|, 2)          ->   c/d
|a/b/c/d|.avant.dernier(|/|)     ->   a/b/c
|photo.final.jpg|.apres.dernier(|.|)   ->   jpg
|un deux trois|.apres(2)         ->   trois
liste(|a/b|, |c/d|).avant(|/|)   ->   liste(|a|, |c|)

entre

texte.entre(debut, fin)
  • Renvoie la LISTE de tous les morceaux de texte compris entre un debut et le fin qui le suit, lus de gauche a droite.
  • Rien trouve : liste vide (pas d'erreur). Un debut sans fin apres lui est ignore. Le debut et la fin peuvent etre le meme texte : |a ! b ! c|.entre(|!|, |!|) donne liste(| b |).
  • Pour recuperer seulement le premier morceau : texte.entre(|[|, |]|)[1] (verifier avec .lon() qu'il y en a au moins un).
  • Debut ou fin vide : erreur claire. S'applique a un texte.
Voir l’exemple
|x [a] y [b] z|.entre(|[|, |]|)   ->   liste(|a|, |b|)
|rien|.entre(|[|, |]|)   ->   liste vide
|<b>1</b> et <b>2</b>|.entre(|<b>|, |</b>|).joindr(|+|)   ->   1+2

garder · enlever

x.garder(valeur, ...) / x.enlever(valeur, ...) / x.garder.contenant(valeur, ...) / x.enlever.contenant(valeur, ...)
  • garder garde seulement ce qui correspond, enlever retire ce qui correspond. Plusieurs valeurs possibles : l.garder(|a|, |b|) garde les elements egaux a a OU a b. Le resultat est du MEME type que x (texte, liste, vecteur ou dictionnai) ; x n'est pas modifie.
  • Liste ou vecteur : un element correspond s'il est EGAL a la valeur. liste(|a|, |ab|, |a|).garder(|a|) donne liste(|a|, |a|).
  • Texte : on garde ou on retire les LETTRES presentes dans les valeurs. |a1b22c|.garder(|0123456789|) donne 122, |banane|.enlever(|a|) donne bnne.
  • Dictionnai : on agit sur les CLES. d.garder(|nom|, |age|) garde seulement les entrees de ces cles.
  • garder.contenant et enlever.contenant : un element correspond s'il CONTIENT la valeur. Un texte la contient comme morceau de texte, une liste ou un vecteur si un de ses elements lui est egal, un dictionnai s'il a cette cle ; un nombre ne contient rien (garder.contenant ne le garde pas, enlever.contenant le garde). Sur un dictionnai, on regarde ses cles (texte contenant la valeur).
  • Un seul niveau : les listes imbriquees ne sont jamais fouillees plus profond (une sous-liste est un seul element).
  • Erreurs claires : aucune valeur donnee, valeur vide dans .contenant, .contenant sur un texte (pas de sens).
Voir l’exemple
liste(|a|, |ab|, |b|).garder(|a|)              ->   liste(|a|)
liste(|a|, |ab|, |b|).garder.contenant(|a|)    ->   liste(|a|, |ab|)
liste(|a|, |ab|, |b|).enlever.contenant(|a|)   ->   liste(|b|)
c(1, 2, 1, 3).enlever(1)                       ->   c(2, 3)
|a1b22c|.garder(|0123456789|)                  ->   122

correspond · trouve · trouve.tout

x.correspond(motif) / x.trouve(motif) / x.trouve(motif, groupe) / x.trouve.tout(motif) / x.trouve.tout(motif, groupe)
  • Un MOTIF (expression reguliere) decrit une forme de texte. m|\d+| est un motif qui trouve un nombre ; m|abc|i ignore les majuscules ; fam|...| fabrique un motif avec des {variables}. Options apres la barre fermante : i (ignorer les majuscules), m (^ et $ ligne par ligne), s (le point accepte aussi le saut de ligne).
  • Dans m|...| et fam|...|, les antislashs vont tels quels au motif (\d, \s, \.) ; \| est l'ALTERNATIVE : m|chat\|chien| = chat ou chien. Pour chercher une vraie barre, ecris [\|] ou \x7C : m|a[\|]b| et m|a\x7Cb| cherchent a|b.
  • x.correspond(motif) renvoie VRAI ou FAUX. x.trouve(motif) renvoie le premier morceau qui correspond, ou un texte vide s'il n'y en a pas (jamais d'erreur). x.trouve.tout(motif) renvoie la liste de tous les morceaux (liste vide s'il n'y en a pas). Un texte ordinaire n'est pas un motif : pour chercher un texte tel quel, ecris fam|{x}|.
  • Groupes : les parentheses du motif isolent des morceaux. trouve et trouve.tout acceptent apres le motif un numero de groupe (0 = tout le morceau) ou un nom : avec (?<mois>\d+) dans le motif, x.trouve(motif, |mois|). Groupe inexistant : erreur claire.
  • fam|...| : {x} insere la variable x (un texte ou un nombre est cherche tel quel, un motif est insere avec son sens et ses options) ; {x!m} insere un texte comme vrai motif ; {n!c} donne un nombre de repetitions ({3}) et exige un entier positif ; {3} et {2,5} restent le comptage du motif ; \{ est une vraie accolade. Un motif refuse par le moteur donne l'erreur « motif invalide : ... ».
  • decoup et remplace acceptent aussi un motif (voir ces commandes).
Voir l’exemple
|Tel 12 et 34|.correspond(m|\d+|)          ->   VRAI
|Tel 12 et 34|.trouve(m|\d+|)              ->   12
|Tel 12 et 34|.trouve.tout(m|\d+|)         ->   liste(|12|, |34|)
|18-10-2026|.trouve(m|(?<mois>\d+)-(\d+)|, |mois|)   ->   10
|18-10-2026|.remplace(m|(\d+)-(\d+)-(\d+)|, |$3-$2-$1|)   ->   2026-10-18
n ~ 3   puis   |123|.correspond(fam|^\d{n!c}$|)   ->   VRAI

touche

touche()
  • Lit une touche du clavier SANS ATTENDRE (contrairement a entr(), qui bloque jusqu'a la saisie) : renvoie tout de suite la plus ancienne touche pressee depuis le dernier appel, ou un texte vide || s'il n'y en a aucune.
  • La touche est renvoyee TELLE QUE LE CLAVIER L'ANNONCE, le langage ne la traduit pas : a, z, 1 (avec Maj : A, Z), ArrowUp, ArrowDown, ArrowLeft, ArrowRight (fleches), Enter, Escape, Backspace, Tab, et un espace (| |) pour la barre d'espace. Pour ignorer Maj, ecris k.miniscul() (ou touche().miniscul()) : c'est une methode de texte, comme .majuscul() et .suprespac(). Un bouton cree avec bouton(...) renvoie la valeur que tu as choisie.
  • Commande autonome, comme entr() : aucun bouton ni champ n'est affiche. Le premier appel ouvre le clavier du telephone (comme entr()) et active la lecture du clavier physique, sans jamais bloquer le script. Si le clavier est ferme, toucher la console le rouvre ; il se ferme a la fin du script. Pour des touches visibles, construis-les toi-meme avec bouton(...).
  • Les touches pressees entre deux appels sont gardees dans l'ordre (les 64 dernieres) : touche() les rend une par une. Mets un attendre(...) dans ta boucle de jeu pour fixer la vitesse.
  • Indisponible en arriere-plan (bouton FOND) : lance le script avec RUN.
Voir l’exemple
x ~ 5
tanqer VRAI{
  k ~ touche()
  si(k == |q| ou k == |ArrowLeft|){ x ~ x-1 }
  si(k == |d| ou k == |ArrowRight|){ x ~ x+1 }
  si(k == |Escape|){ quitte }
  effa()
  affi(|x =|, x)
  attendre(0.1)
}

doigt

doigt()
  • Lit l'evenement tactile le plus ancien sur la zone : liste(x, y, etat). x et y sont dans les coordonnees de la zone (0,0 en haut a gauche), etat vaut |appui| (le doigt se pose), |bouge| (il glisse) ou |fin| (il se leve). Sans evenement, renvoie une liste vide : teste avec doigt.dispo().
  • Un appui dans les bandes noires autour de la zone est ignore, mais un glissement qui sort de la zone continue d'etre suivi (x et y peuvent alors depasser la zone). Les deplacements successifs sont fusionnes : tu lis la position la plus recente. Un seul doigt est suivi a la fois.
  • Separe de touche() et des boutons : les deux files ne se melangent pas. Un balayage se calcule en comparant l'|appui| et la |fin|.
Voir l’exemple

  si(doigt.dispo()){
    d ~ doigt()
    affi(d)
  }
  attendre(0.02)
}

  • Contrairement a son(), c'est une alerte NATIVE : elle passe par le canal audio ALARME d'Android, comme l'application Horloge. Elle sonne meme si le telephone est en silencieux ou en vibreur, et marche aussi en arriere-plan (FOND, scripts planifies).
  • nom : |defaut| (le son d'alarme choisi dans les reglages du telephone), |sirene| ou |bip| (sons generes). duree : en secondes, au plus 300 (arrondie a la seconde superieure). volume (facultatif) : de 0 a 1, regle le volume d'alarme le temps de l'alerte puis le remet comme avant ; sans lui, c'est le volume d'alarme que tu as regle.
  • Limites : un volume d'alarme a zero rend l'alerte muette (donne un volume), et le mode Ne pas deranger peut la bloquer si l'exception des alarmes y est desactivee. Disponible uniquement dans l'app installee. Voir alerte.mode pour ce qui se passe a la fin du script.
Voir l’exemple
alerte.son(|defaut|, 30)

a ~ alerte.son(|sirene|, 10, 1)
attendre(3)
alerte.arrete(a)

(2 a 50 valeurs, chacune au plus 60000, 300 secondes au total ; la 1re valeur est une PAUSE, 0 pour vibrer tout de suite). Elle doit contenir au moins une vibration.

zone

zone(largeur, hauteur) ou zone(largeur, hauteur, couleur)
  • Cree une zone de dessin, posee par-dessus l'affichage texte de la console. Sans zone.cadre(...), elle couvre tout l'espace libre (entre l'en-tete et les boutons) ; avec, elle n'en occupe qu'une partie et les affi(...) restent visibles autour. largeur et hauteur sont des unites a toi (pas des pixels) : la zone est etiree pour remplir l'ecran en gardant ses proportions, donc ton jeu a les memes proportions sur tous les telephones. Le point (0, 0) est en haut a gauche et y augmente vers le bas.

C'est le fond du rectangle de dessin lui-meme ; les bandes autour, quand les proportions different de celles du cadre, se colorent avec zone.cadre(..., couleur).

Graphique

trac

trac(x, y, ...) ou trac(y, ...)
  • Trace une courbe dans la console, sous forme d'image (canvas) — comme plot(x,y) en Scilab.
  • Les points doivent d'abord etre calcules (avec une boucle pou, ou une expression vectorielle comme y~x*x), puis on appelle trac.
  • trac(x, y) : trace le vecteur y en fonction du vecteur x (memes longueurs).
  • trac(y) : trace le vecteur y en fonction de sa position (1, 2, 3...).
  • Par defaut, la grille n'est pas affichee (comme en Scilab) : utilise grille() pour l'activer.
  • Options facultatives (a la suite, dans n'importe quel ordre) : couleur~|...|, style~|...|, legende~|...|, titre~|...|, xlab~|...|, ylab~|...|, epaisseur~nombre.
  • epaisseur : epaisseur du trait en points de dessin, de 0.5 a 20 (2 par defaut), ex: epaisseur~4. Elle agit sur le trait, pas sur la taille des marqueurs.
  • Aucune droite d'axe n'est tracee par defaut (comme en Python) : le repere a son cadre et ses graduations. Pour tracer les axes qui se croisent au milieu (en 0), utilise axes(), axe.horizontal() ou axe.vertical().
  • couleur (comme en Scilab, mais en francais) : r=rouge, v=vert, b=bleu (par defaut), n=noir, j=jaune, m=magenta, c=cyan, bl=blanc. On peut aussi mettre un nom comme dans zone() : |rouge|, |vert|, |bleu|, |jaune|, |orange|, |violet|, |rose|, |cyan|, |blanc|, |noir|, |gris|, |marron|, ou un code hexadecimal, ex: couleur~|#ff00aa|.
  • style : que des symboles. Lignes : |-| trait continu (par defaut), |--| tirets, |:| pointilles. Marqueurs : |o| cercles, |.| petits points, |+| croix, |x| croix en diagonale, |*| etoile, |^| triangle, |#| carre. Un marqueur seul trace des points sans trait ; on peut combiner une ligne et un marqueur : |-o|, |--+|, |:^|. Toute autre valeur donne une erreur. (L'ancien nom de cette option, type~, donne une erreur qui indique d'utiliser style~.)
  • legende : le nom de la courbe. Des qu'une courbe a un nom, un petit cadre de legende apparait dans un coin du graphique ou aucune courbe ne passe (haut droit en priorite) ; si les quatre coins sont traverses, il se place au-dessus du graphique, qui se reduit d'autant : la legende ne cache jamais une courbe. Une ligne par courbe nommee (echantillon du trait et du marqueur dans sa couleur, puis son nom). Les courbes sans nom n'y figurent pas. Exemple : trac(x, y, couleur~|r|, legende~|vitesse|). 12 noms au plus sont affiches (les autres sont comptes), chaque nom est limite a 30 caracteres.
Voir l’exemple
x ~ seq(-5,5,0.1)
y ~ x*x
trac(x, y, couleur~|r|, style~|-|, titre~|Ma courbe|)

trac.multi

trac.multi(x, y1, y2, ...)
  • Trace plusieurs vecteurs y en fonction du meme vecteur x, sur un seul repere (comme plot(x, y1, y2) en Scilab).
  • Sans option couleur, chaque courbe prend automatiquement une couleur differente. Les options facultatives couleur~, style~, legende~, epaisseur~, titre~, xlab~ et ylab~ s'ecrivent comme pour trac. Avec un TEXTE (couleur~|r|), elles valent pour toutes les courbes : elles ont donc la meme couleur.
  • Pour choisir une valeur PAR COURBE, donne une LISTE a couleur~, style~ et/ou epaisseur~ (epaisseur~liste(1, 3, 5)) : une valeur par courbe, dans l'ordre, ni plus ni moins (sinon erreur). Exemple : trac.multi(x, y1, y2, y3, couleur~liste(|r|, |vert|, |#ff8800|), style~liste(|-|, |--|, |o|)). titre~, xlab~ et ylab~ restent communs a toutes les courbes.
  • legende~ s'utilise aussi avec une liste, un nom par courbe : legende~liste(|vitesse|, |acceleration|, |position|). Avec trac.multi, elle n'accepte QUE une liste (un nom commun a toutes les courbes n'aurait pas de sens), et la liste doit avoir une valeur par courbe.

Image finale = taille x resolution (1280 x 832 par defaut). Plus la mise en page est grande, plus le texte parait petit ; une resolution plus haute rend le meme dessin plus net. Maximum 16 millions de pixels.
  • Chemin complet avec / (ex: |/sdcard/Download/courbe.png|), ou juste un nom : une fenetre propose l'emplacement. Un fichier existant est refuse sauf ecra~VRAI. Sans extension, .png est ajoute. Dans l'app installee seulement (dans un navigateur, l'image est telechargee).
Voir l’exemple
x ~ seq(-3,3,0.1)
trac(x, x*x, legende~|x^2|, titre~|Deux courbes|)
trac(x, x*x*x, legende~|x^3|)
trac.enregistre(|/sdcard/Download/courbes.png|, largeur~800, resolution~3)

feuille.enregistre

feuille.enregistre(chemin, ...) ou feuille.enregistre(n, chemin, ...)
  • Enregistre en UNE image toute la feuille : tous les graphiques de sa grille (trac.diviser), chacun avec ses courbes. Sans numero, la feuille active ; avec n, la feuille numero n. Une case jamais utilisee reste vide.
  • Memes options que trac.enregistre. Ici largeur~ et hauteur~ donnent la taille de TOUTE l'image (en points de dessin) ; par defaut chaque graphique fait 640 x 416 plus des marges.
Voir l’exemple
x ~ seq(-3,3,0.1)
trac.diviser(1, 2, 1)
trac(x, x*x)
trac.diviser(1, 2, 2)
trac(x, x*x*x)
feuille.enregistre(|/sdcard/Download/feuille.png|)

grille

grille() ou grille(FAUX)
  • Active ou desactive la grille sur le dernier graphique trace avec trac(...) — comme xgrid() en Scilab.
  • grille() : active la grille (par defaut, elle n'est pas affichee).
  • grille(FAUX) : desactive la grille.
  • Doit etre appelee apres trac(...).
Voir l’exemple
x ~ seq(-5,5,0.1)
y ~ x*x
trac(x, y)
grille()
22. Compléments de l’IDE et du moteur v4.0 (02/10/2026)

Cette section complète les règles précédentes à partir du fichier actuel index.html. Elle décrit les capacités intégrées à l’IDE et les limites d’exécution à respecter.

23.1 Éditeur et fichiers

  • L’éditeur prend en charge plusieurs onglets de code, l’ouverture de fichier, la création d’un nouvel onglet et l’enregistrement.
  • La barre d’outils propose déplacement du curseur, annuler, rétablir, recherche et collage.
  • Le navigateur de fichiers intégré permet de parcourir les emplacements accessibles à l’application. L’accès dépend des autorisations et du contexte Android/Web.

23.2 Interface interactive

  • bouton(...) crée des boutons utilisables depuis la console ; leur zone est masquée lorsqu’aucun bouton n’est demandé.
  • Les positions peuvent être organisées sur une grille et ajustées avec les commandes de positionnement documentées dans l’aide native.
  • La zone de dessin utilise un élément Canvas. Les fonctions de dessin et de graphique disponibles sont celles exposées par le moteur ; cela ne signifie pas qu’une bibliothèque 3D externe est incluse.
  • touche() et touche.dispo() permettent de lire les frappes prises en charge par l’interface.

23.3 Exécution et arrière-plan

  • L’IDE distingue l’exécution normale et l’exécution en arrière-plan Android via le service prévu par l’application.
  • En arrière-plan, entr() n’est pas disponible, car aucune saisie interactive de console n’est présentée au script.
  • La continuité d’exécution reste soumise aux règles du système Android, à l’état du service et aux restrictions énergétiques de l’appareil.
  • L’arrêt d’urgence est une commande de l’interface d’exécution ; il ne faut pas confondre cela avec une garantie d’exécution illimitée.

23.4 Paquets et modules

  • La console comporte un accès au gestionnaire de paquets.
  • Les commandes de gestion exposées dans l’aide native comprennent install.paquet(), desinstall.paquet(), liste.paquet(), info.paquet() et paquet.dispo(), ainsi que connexion.depot(), deconnexion.depot() et publier.paquet() pour publier sur le depot, ainsi que retirer.module() et retirer.paquet() pour y supprimer.
  • Les commandes qui utilisent internet affichent des lignes grises « en cours » (connexion, telechargement 2/3...) et peuvent etre arretees avec Stop. Les echecs sont expliques : pas de connexion internet, connexion trop lente, limite de requetes GitHub, jeton refuse, fichier corrompu sur le depot (index.json, paquet.json ou module absent). Un paquet installe incomplet ou corrompu est signale par liste.paquet et info.paquet avec la marche a suivre (desinstall.paquet puis install.paquet).
  • Les imports locaux et les paquets installés sont deux mécanismes à distinguer. La disponibilité d’un paquet dépend du dépôt et de son installation effective.

23.5 Aide de référence

aide() affiche l’index compact des signatures ; aide(nom) affiche la description et l’exemple d’une entrée ; aide(spec) ouvre cette spécification. Pour la signature exacte d’une commande récente, l’aide native du moteur constitue la référence à confronter à cette documentation.

23. Son et vibration (02/10/2026)

Cette section décrit uniquement les commandes présentes dans l’aide du moteur actuel : son(), note(), son.arrete() et vibre(). Les sons du jeu sont synthétisés par Web Audio, sans fichier audio.

24.1 Effets sonores

son(effet) ou son(effet, volume) joue un effet et renvoie son numéro. Effets reconnus : bip, clic, pop, piece, saut, tir, explosion, perdu, gagne. Le volume facultatif va de 0 à 1, avec 1 par défaut.

L’appel ne bloque pas le script. Jusqu’à 16 sons peuvent être actifs ; lorsqu’une nouvelle voix dépasse cette limite, la plus ancienne est coupée. Le son suit le volume média du téléphone et peut être inaudible en mode silencieux. Il s’arrête avec le script et n’est pas disponible en arrière-plan (FOND).

24.2 Notes musicales

note(frequence, duree), note(frequence, duree, volume) ou note(frequence, duree, volume, forme) joue une note et renvoie son numéro. La fréquence est comprise entre 20 et 20000 Hz, ou peut être un nom de note : |do4|, |la4|, |do#3|, |solb5|. Si l’octave est omise, l’octave 4 est utilisée. La durée va de 0,01 à 10 secondes ; le volume de 0 à 1 (1 par défaut). Formes : |sinus| (défaut), |carree|, |triangle|, |dent|. Pour choisir une forme, il faut aussi fournir le volume. L’appel ne bloque pas ; pour enchaîner les notes, utiliser attendre() entre elles. Les mêmes limites de lecture au premier plan et de volume que son() s’appliquent.

24.3 Arrêt des sons

son.arrete() coupe tous les sons du jeu. son.arrete(numero) coupe le son correspondant au numéro renvoyé par son() ou note(). Un numéro inconnu ou déjà terminé est ignoré. Tous les sons sont également arrêtés à la fin du script.

24.4 Vibration

vibre(ms) déclenche une vibration de 0 à 5000 millisecondes. vibre(liste(pause, vibration, pause, ...)) accepte un motif alternant pause et vibration, limité à 20 valeurs. vibre(0) arrête la vibration. L’appel ne bloque pas le script. La vibration suit les réglages du téléphone, s’arrête avec le script et n’est pas disponible en arrière-plan (FOND). Si l’appareil ne dispose pas de vibreur, l’appel est ignoré.

24.5 Limites documentées

Les commandes de son et de vibration décrites ici sont destinées à l’exécution RUN au premier plan. L’aide du moteur mentionne alerte.son et alerte.vibre comme alternatives natives pour les alertes en arrière-plan ou devant fonctionner même en mode silencieux ; cette spécification ne leur attribue pas d’autres signatures ou garanties non détaillées dans l’aide.

son(|piece|)
son(|explosion|, 0.5)
s ~ note(|do4|, 0.2)
attendre(0.2)
note(|mi4|, 0.2)
attendre(0.2)
son.arrete(s)
vibre(80)
vibre(liste(0, 200, 100, 200))
